# 卡牌功能识别构图样稿 v04

先验证射击、守护铃和烟幕三张。风格继续使用几何块面、圆润道具和森林色；焦点改为卡牌的主要动作或效果。

- 射击：大弓、单支离弦箭、向外发力的斜线；人物只保留持弓的手。
- 守护铃：主体是完整的叶形保护屏障，小铃提供来源提示，一支来箭止于屏障。
- 烟幕：横向包覆的大烟团，人物仅露出小块帽子和背影；火把处于次要位置。

三张彩色 SVG 与每张两种灰度构图位于本目录。A 是当前细化构图的去色对照，B 是另一种构图的草图探索，不把灰度细化图冒充最初草图。

源码：`tools/build_card_readability_study.py`。SVG 为 640×400 构图、1280×800 导入尺寸，无卡名和费用文字。六张原有人物卡和两套主角外观保持原样。

`tests/capture_card_readability_study.gd` 会临时把三张纹理放入真实试玩，捕获同一战斗状态的前后对照和小窗口画面，不修改正式资源映射、牌定义或游戏包。生成图位于 `screenshots/card_readability_v04/`。这轮是视觉样稿，未做玩家识别率盲测。
