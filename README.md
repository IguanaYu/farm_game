# 小小农场（单人首版）

点击式种田游戏：在立体农场里直接点击地块与建筑操作，作物按现实时间生长（关游戏也继续）。完整循环：**选种 → 播种与照料 → 成熟收获 → 育种或复制 → 比价出售 → 购买、扩地与升级 → 下一轮**。

第二大阶段“农场与合作洞窟”：**功能已实现**——战备箱配装 → 下洞（一层苔石浅洞／二层铁根矿窟／三层晶脉矿窟）→ 卡牌战斗与搜刮 → 撤离或深入 → 回家制作/种植/成长；双人合作走主机裁定。**自动化回归通过**：2026-10-02 修复轮批次 A~E 后经 [d996462 复核](docs/testing/Farm_反馈复核_d996462_2026-10-02.md) 判定 F-03／F-06／F-10 部分完成，2026-10-04 按[复核关闭轮计划](docs/plan/Godot_复核关闭轮_F03F06F10_代码执行计划_v0.1.md)补齐（占用落盘后才发回执、收集器白名单按内容匹配＋负向测试、文档口径三层化）。**实机验收**：R0~R7 离线链路全绿；线上 D-01 登录断连循环已修（f9c3393），线上用例复验与真人双机公网验收待做。进行中记录见 [docs/testing](docs/testing/)。

## 玩法速览

- **主菜单与暂停**：启动先进主菜单（继续 / 开始新游戏 / 设置 / 退出）；游戏内按 `ESC` 弹暂停菜单可回主菜单（联机房间或对局进行中该按钮置灰）。设置含窗口模式、重新显示新手引导、联机服务器地址（与房间页共用）。"开始新游戏"覆盖旧档前会弹确认，旧档自动进 `farm_save_v1.json.bak` 备份。
- **地块**：空地点击→选种播种（能看到词条与品质）；生长中点击→照料（分时段浇水、施肥）；成熟点击→收获（面板逐项解释分数构成）。金色浮动标记=可收获。
- **照料**：浇水免费，每个有效时段只记一次（白菜 1 段，2 小时植物 2 段）；肥料每次覆盖 2 小时、可跨多轮，未到期不能换。水壶 2 级一次浇 3 块地、每时段 +20%。
- **育种**：收获的 2~3 粒新种子各自独立判定词条（继承→升档→新词条）；在仓库种子区比较、回收（5 金币/粒）、设为育种机模板。育种机定期复制模板（离线也计时，满了暂停）。
- **集市**：每天北京时间零点刷新三位客人与两种植物的收购公式；可锁客人（商店 2 级）、锁公式类型（商店 3 级）。卖菜可拆批比价，或默认 1.2 倍兜底。金克拉批次倍率 +0.2。
- **升级**：商店（折扣 5%/级）、仓库扩容、水壶 2 级、育种机、扩地到十块。具体价格在游戏内商店查看。
- 新档有五步引导，可跳过。

## 矿洞卡牌界面

2026-10-12 已精简卡牌与相邻界面：卡面只常显费用、名称、插画、短效果与特殊规则；来源装备和完整说明悬停查看，战场以图标和数值表达状态。玩家与队友站在左侧、敌人站在右侧，共用洞窟背景和地面，生命与格挡跟随角色。右上角齿轮统一打开设置，试玩的重开、返回首页与测试选项收进菜单，说明和记录也在菜单内；Esc 开关菜单，选牌时优先取消。搜刮、配装、营地和路线缩短文案，适配 1024×640。首页与探险菜单采用桑葚紫、陶土橙、米白纸页，搭配种子印章和不对称页角；设置与配装沿用同一套浅色主题。见 [精简与验证记录](docs/design/Farm_卡牌UI精简_2026-10-12.md)、[菜单主题记录](docs/design/Farm_菜单主题_2026-10-12.md)、[当前首页](screenshots/card_berry_theme_2026-10-12/23_home.png) 和 [当前战斗](screenshots/card_berry_theme_2026-10-12/01_battle.png)。

此前试玩反馈已加入：同一具尸体的全部包裹同屏展开，装备使用白／蓝／紫／金／红五档品质与不同搜索时长；卡牌悬停可查看来源装备，自身牌点击即用，出牌、叠甲、命中、治疗和抽牌有动画反馈。试玩设置的「试玩选项」可指定品质测试，切换会恢复初始装备并重开。见 [实施与验收](docs/testing/Farm_多包同屏_品质与卡牌反馈_2026-10-05.md) 和 [历史画面](screenshots/quality_feedback/README.md)。

矿洞界面已更新为探险营地、路线预览与卡牌战场；支持拖牌出牌、合法目标高亮、伤害预览、牌堆查看和快捷键。设计与验证记录见 [矿洞卡牌 UI 重设计](docs/design/Farm_矿洞卡牌UI_重设计_2026-10-03.md)，预览见 `screenshots/expedition_redesign/`。

战斗胜利后进入“清理战场”：点击倒下的野怪，按物品实际占格显示未知轮廓，例如盾牌 2×2、短剑 1×3；圆环在整块中央搜索，结束后整件揭晓。名称、图标、品质与属性仍在搜索后显示。多名敌人留下各自的遗骸；第一层中段新增带铜短剑、护具、腰包和背包的骷髅巡逻兵，各区域独立搜索。已发现物品可以立即拖入胸挂／背包，拖动时按 R 旋转，容量允许就能拿走；原来的战斗任选一件规则只保留在已裁定的旧局节点。关闭或切换区域会中断当前搜索，已发现物品和已领取状态保留。合作时共享搜索结果，物品全队一份。

宝箱和采集节点继续使用原搜刮台。所有搜刮界面都能比较售价、占格、牌效和货物负担，整理胸挂／背包／保险箱，丢弃后可在离开前捡回。规则见 [战后搜刮台](docs/design/Farm_战后搜刮台_2026-10-03.md)，最新预览见 [尸体搜索画面](screenshots/corpse_loot/README.md)。搜索时长与新增敌人数值仍是待试玩初值。服务端代码已通过本地真实 WSS 回归，公网服务尚未同步部署本次改动。

## 已知限制

1. 单人本地存档（`user://farm_save_v1.json`，内容版本 v7，含洞窟/制作进度），无云存档；设备时钟可被修改，会影响离线成熟、每日客人与育种机结算。
2. 六位客人为默认静态造型；参观时的形象不表示在线玩家的实时位置，家居使用默认模板。
3. 调试按键 F9（全部立即成熟）只在开发构建可用，导出包无效。
