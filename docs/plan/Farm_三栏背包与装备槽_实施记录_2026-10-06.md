# 三栏背包与装备槽改版 · 实施记录（2026-10-06）

仿三角洲行动的三栏背包与搜刮改版。本文件是落地记录（口径以代码与测试为准）。

## 一、玩家侧布局（战备＝农场侧 / 搜刮＝局内共用）

```
┌────────┬───────────────┬────────────┐
│ 装备区   │ 容器区(纵向滚动)  │ 仓库(农场侧)   │
│ [头盔]   │ 胸挂 [贴图|格子]  │ 大格子视图      │
│ [主武][护甲][副武] │ 背包 [贴图|格子] │ (局内右栏换成   │
│ (暗黑T形) │ 保险箱[贴图|格子] │  尸体/物资视图) │
└────────┴───────────────┴────────────┘
```

- 共享组件 `scripts/ui/backpack_workspace.gd`（BackpackWorkspace）：装备纸娃娃（暗黑 T 形四槽，
  尺寸可配置，搜刮台用紧凑版）＋容器栈（胸挂/背包/保险箱，块＝容器贴图｜格子，纵向滚动）＋
  FlowItemGrid（自动装箱流式大格子，仓库与物资"巨大背包"共用）。
- 拖放协议：payload 带 `workspace_owner` 归属校验；类别不符装备槽画红 ghost；换装旧件自动回仓库；
  容器放置沿用占格/旋转/R 键；`place` 语义会清 `slot` 字段。

## 二、域层口径

- **装备槽**：`loadout["equipped"]`，实例带 `slot`（main_weapon/off_weapon/helmet/armor），不占容器格；
  归属唯一扩展到 equipped。槽位接受性按类别（weapon→主/副武器、helmet→头盔、armor→护甲）。
- **洗牌轮次**（`JOIN_ROUND`）：装备槽第 1 回合、胸挂第 2、背包第 3；**保险箱永不入堆**
  （纯保险仓：死亡保留、不给牌）。抽牌堆抽空重洗弃牌堆时不分轮（原行为不变）。
  `is_container` 改按 CONTAINERS+warehouse+equipped 判定（safe 移出 JOIN_ROUND 不影响放置）。
- **新物品**：草帽 straw_hat（helmet 类，基础套装，2×2=4 张防守辅助牌）、铁盔 iron_helm
  （L3 宝箱/守门掉落）。`item_art` 映射加 helmet。
- **预设 FMT=2**：capture/apply 含 `equipment` 段（槽位精确复原）；fmt1 旧档兼容读取。
- **结算**：装备槽按未保护携带处理——死亡/放弃损失、撤离带回且保持装备状态；保险箱白名单保留不变。
- **服务器**：`inv.equip`/`inv.unequip` 命令；claim_reward/claim_loot_instance/pick_node_drop
  支持 `container=equipped`+`slot`（从尸体/奖励/捡回直接穿上）；局内 `loot_manage` 增
  equip/unequip 两个 op（联机层泛转发，协议不变）。
- **旧档迁移**：农场档 loadout 缺 `equipped` 时补空数组（不动存档版本）。

## 三、敌人尸体（右栏上下文·尸体模式）

```
┌ 掉落装备（顶部 2×2 固定槽框）────────┐
│ [主武器?][副武器 —空]                  │ ← 每个非空槽＝独立搜索区，最先扫；
│ [头盔 —空][护甲?]                      │    空槽灰框、不参与扫描
├───────────────────────────────────┤
│ 胸挂 [小格]（绷带等杂物）               │
│ 背包 [小格]（个人战利品掉落进这里）      │
│ 地上 · 最后搜索 [横条]（默认空区；      │
│   特殊情况物品进此区，链序垫底）         │
│ 现场丢弃捡回按钮并入地上条区域            │
└───────────────────────────────────┘
自动接续顺序＝主武→副武→头盔→护甲→胸挂→背包→地上（regions 数组顺序即链序）
```

- 人形敌人（骷髅巡逻兵等带 equipment 的）用上述布局；野兽保留单一「遗骸」区＋地上条。
- ENEMIES 装备字段扩展：weapon/offhand/helmet/armor + 可选 `drop_odds`（默认 1.0 必掉，概率留接口）。
- 搜索/占用/投影契约（unknown 足迹、epoch 租约、claim_corpse op）零改动。
- 物资模式（宝箱/采集/无尸体奖励）：奖励＋公共＋现场丢弃合成流式大格子，拖到装备槽/容器格。

## 六、排障记录（坑速查）

- 外层 Control 不自算子项最小尺寸：SHRINK_BEGIN 场景必须显式 `custom_minimum_size`
  （按纸娃娃行实际宽＝三槽+间距计算），否则被压 0 宽、内容溢出叠压邻栏、点击落空。
- `select_item` 不能重建上下文栏：按下瞬间释放拖动源控件，拖放启动即失败。
- 容器块标题行在窄栈中会右溢出：caption 需 clip_text+overrun。
- 拖动源/落格期间不要 `ExpeditionUI.clear` 宿主容器；布局重建前先摘除常驻子节点。
- Python 批量补丁注意保持目标文件行尾（CRLF 文件里混入 LF 会让后续字符串匹配 MISS）。
