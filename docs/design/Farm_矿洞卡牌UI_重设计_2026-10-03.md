# 矿洞卡牌探索界面重设计

本轮已实现探险营地、路线、战斗、搜刮与结算界面的更新。以深蓝矿石色、暖金灯光、纸质手牌和原生矢量插画建立统一风格。农场与战备箱原有功能继续接入这些页面。

## 页面与操作

- **营地**：三层矿洞的介绍、牌组总数、首回合可用牌数、出发检查和基础装备引导。空牌组禁用出发，活动局提供继续入口。战备、装备仓库、组队入口集中在出发准备区。
- **路线**：自下向上展示实际路线，相邻排全连通。只在真实当前位置标记菱形；已完成节点有勾选。点击下一排先看风险与已知遭遇，再确认前进；合作局确认时发送选路投票。
- **战斗**：战场在上、手牌在下。敌人有插画、意图、生命条、格挡和状态；合作局同时标注意图的目标。自身及队友状态在左侧。
- **手牌**：展示费用、主要效果、目标类型、弃牌/本场移除/消耗来源物品。攻击、防御、恢复、辅助用不同配色和图案。费用不足时置灰，悬停仍可读完整描述。
- **目标**：点击选牌后高亮合法目标，可点击目标或直接拖牌到目标。攻击预览包含伤害、格挡后的生命损失及击败提示。伤害数值与目标合法性由 CombatGame 的预览接口提供。
- **快捷键**：1–9、0 选择当前顺序第 1–10 张牌；E 结束回合；右键或 Esc 取消选牌。再次点选已选中的自用牌可直接使用。牌堆查看时 E 不生效，Esc 关闭查看。
- **牌堆与记录**：抽牌堆、弃牌堆、移除堆可按牌名和数量查看，抽牌顺序不公开。战斗和探险记录按需展开。十张手牌横向滚动。
- **搜刮**：候选物品以独立卡片展示尺寸、牌数与可售价值；背包和保险箱常显使用格数及最大空位。奖励确认仍使用既有事务接口。
- **撤离与结算**：出口节点补齐撤离和深入按钮。撤离确认展示带入装备、新增战利品、保护区与当前生命；结算需确认回家，Esc 不会绕过结算确认。长弹窗可滚动。

## 流程修正

领取判断使用本人 claimed 记录，二选一锁定后不再计算已放弃候选；领完可领取物品后不再错误提示仍有未领取物品。被放弃的二选一候选与真正领取的物品使用不同标记。

合作战斗保留主机裁定入口和 p1/p2 视角。客机提交行动后暂时锁住重复操作，按 action_id 匹配回执，并等权威快照后解锁。镜像更新保留已选牌及查看状态；结束行动后不能继续出牌。界面不直接裁定客机行动。

本轮没有改动战斗数值、卡牌定义或存档结构。矢量素材集中在 `scripts/ui/expedition_art.gd`，涵盖现有全部敌人；共用配色与控件状态在 `scripts/ui/expedition_ui.gd`。

## 验证

`tests/capture_expedition_redesign.gd` 使用独立内存档和不落盘的探险实例，不读取玩家存档。真实 GUI 点击与鼠标拖放覆盖选牌、合法目标、格挡后的伤害预览、自用牌、费用禁用、快捷键、弹窗拦截、异步重复提交、路线预览/确认、奖励领取、出口撤离和强制结算确认。无头检查及 Vulkan 实机运行均通过；实机生成 15 屏预览，包含 1280×800 与 1024×640 窗口下的十张手牌。

预览位置：`screenshots/expedition_redesign/`。

既有全量回归：49 项中 47 项通过。`d42_online_auth_farm_smoke` 和 `d43_online_client_bridge_smoke` 因当前 worktree 没有 `server/secrets/farm_server.crt` 及配套私钥而失败；不应将此轮报告解释为线上农场验证通过。合作局仍是既有同进程真实会话/面板检查，未增加双机实测。
