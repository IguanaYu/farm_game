# 卡牌 UI 精简 · 2026-10-12

目标：常显信息只服务于当前决策；卡面用短效果，详细规则按需查看。

后续主题已统一为桑葚紫、陶土橙和米白，最新配色、26 屏截图及验证见 [菜单主题记录](Farm_菜单主题_2026-10-12.md)。下方截图保留精简和布局调整阶段的版本。

## 实施

- 普通卡面保留费用、名称、插画和核心效果，例如「6 伤害」「3 格挡」。移除来源条、重复目标、默认弃牌和操作句。卡面扩大插画，角落保留快捷键数字。
- 「本场移除」「消耗」「自己 / 队友」「倒地队友」等特殊规则继续常显；易伤、中毒保留名称和数量。完整效果、目标、使用后去向、来源装备及品质放入悬停说明，品质仍体现在卡框。
- 生命、格挡、敌人意图用原生矢量图标和数值表达。零格挡和空状态不显示；连续攻击保留乘数，附带状态保留名称。
- 删除默认战术建议和回合流程长句。选择攻击牌时才出现目标提示与实际效果预览。右上角齿轮打开设置菜单，说明与记录放在菜单内，牌堆仍可查看。
- 试玩工具栏、搜刮、配装、营地与路线预览缩短文案。准备区放到营地顶部；不可出发原因、配装建议、消耗规则、共享物资与离开损失仍可查。
- 1024×640 下缩小插画与牌面高度，合并底部牌堆入口；多手牌通过横向滚动查看。保持主要操作按钮可见。
- 配装与搜刮共用的装备槽名称提高对比度。
- 根据后续反馈，将玩家从左侧独立信息框移入战场，玩家与队友在左、敌人在右。去掉各敌人独立洞窟贴片，共用一个背景和连续地面；双方使用相同插画区域高度，生命、格挡和状态置于角色下方。选目标时才高亮角色区域，合作局保留队友选择与救援。
- 去掉试玩顶部工具栏，将继续、重开本场、返回首页、说明与记录统一放进设置。切换敌人、品质与重置装备折叠在「试玩选项」内；搜刮沿用同一菜单和齿轮入口。重开继续保留本次装包，重置装备清空试玩收获。Esc 开关菜单，选牌/说明打开时先取消或关闭当前内容；菜单遮罩与输入拦截防止误出牌、误结束回合。

展示来自既有规则和状态，战斗数值、存档及服务端协议未修改。装备槽、胸挂、背包的入牌时间分别为第 1、2、3 回合；保险箱不入牌堆。

## 验证

- `d55_card_playtest_smoke`：48 项，首页实际点击、出牌到胜利、搜刮和装包续战、设置里的重开/重置/首页、Esc 层级与菜单防穿透、存档隔离。
- `d56_loot_quality_feedback_smoke`：90 项，品质与来源、真实输入出牌、格挡/伤害/治疗/抽牌反馈。
- `d58_prep_ui_smoke`：23 项，装备槽、容器、配装统计、预设与整理。
- `d32_coop_play_ui_smoke`：合作出牌、结束回合、投票、搜刮与撤离通过；合作战斗的齿轮菜单、快捷键拦截与 Esc 返回通过。
- `capture_card_minimal`：共 22 屏，1280×800 与 1024×640 的引擎截图和操作区域、角色边界与对齐检查，包含多效果手牌、带队友/格挡/中毒的双人战斗、倒地队友救援目标、双人对三敌人、默认设置菜单、展开试玩选项与搜刮设置。位置与菜单调整后重新通过 `d55`（48 项）、`d56`（90 项）与 `d32` 合作流程。
- 重新导出 `build/Farm.exe`，发布包主菜单 headless 启动退出码 0。
