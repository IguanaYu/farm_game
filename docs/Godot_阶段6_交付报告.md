## Windows 导出

- 导出配置：`export_presets.cfg`（Windows Desktop / x86_64 / 内嵌 PCK 单文件 / 产品名"小小农场"）。
- 导出命令：

```powershell
& $godot --headless --export-release "Windows Desktop" --path E:\gpt\godot\farm
# 产物 build/Farm.exe；随后从新档与旧档各试玩一轮
```

- 模板：官方 `Godot_v4.6.1-stable_export_templates.tpz`（1.25GB）下载受网络限制（直连 11KB/s），改走本机 Clash 代理（约 220KB/s）完成后安装到 `%APPDATA%\Godot\export_templates\4.6.1.stable\`。
- **导出结果（2026-09-30 完成）**：`build/Farm.exe` 约 108MB（内嵌 PCK 单文件，已加入 .gitignore 不入库）。编辑器与导出包共用 `user://` 存档（`%APPDATA%\Godot\app_userdata\小小农场\`），导出包直接读到编辑器产生的 v5 旧档并正常游玩，数据一致。
