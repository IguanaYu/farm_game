# 农场与合作洞窟：核心玩法方向 v0.1

整理日期：2026-09-29。本文件记录当前讨论形成的游戏整体方向，重点是玩家反复进行的主循环与长期成长。它是方向稿，不代表洞窟数值、背包规则或开发排期已经定稿。

## 一句话定位

这是一款以**好友合作洞窟探险**为主要玩法、以**农场经营和家园建设**为备战与长期成长的游戏。玩家把已有资源转化为出发装备，在洞窟中通过卡牌战斗、搜刮、选路和撤离获取新资源；成功带回的东西又改善农场、家园和下一次探险的能力。

## 主循环

**经营农场、积累资源 → 选择装备并组队下洞 → 战斗、搜刮、选择路线 → 判断继续深入还是撤离 → 成功带回物品 → 出售、种植、制作、储存或升级家园 → 准备下一次探险。**

- **农场提供稳定的积累与备战。**种地等经营活动让玩家有资源购买、制作或补充进洞装备；玩家不必每次都带昂贵装备，也可以低成本出发。
- **洞窟是主要游玩内容和主线成长途径。**更强的武器、更高级的种子、稀有材料及后续任务目标，主要通过探索洞窟取得。要推进到更深的资源层，玩家需要提高战斗能力，并承担带着收获继续前进的风险。
- **撤离是一次探险的关键决定。**每次有机会撤离时，玩家都要比较已获得的物品、当前队伍状态与更深处的潜在奖励。提前带着收获回家也是成功；死亡则失去本次携带且未受保护的物品。
- **带回的收获推动下一轮。**高级种子可以种出更好的作物；材料可以用于家园升级；武器与其他装备改善下一次进洞的起点。由此形成“农场支持下洞，洞窟反过来改善农场和战备”的循环。

## 一次洞窟探险的核心体验

洞窟参考《杀戮尖塔》的路线选择：队伍在战斗、事件、宝箱和不同风险的区域之间选路。敌人击败后可以搜刮物资；奖励不只是一次战斗后选一张抽象的卡，而是**取得能够带走、使用、出售或投入经营的物品**。

物品与卡牌战斗直接相连：玩家带入或搜到的物品会对应一张或多张卡，当前设想是**物品占几格，就提供几张卡**。例如三格的剑可以提供三张不同的攻击牌，护甲提供防御牌；贵重货物也可能提供较弱、难用或带负面效果的牌。物品的市场价值和战斗价值各自存在，既有“贵但拖累战斗”的货，也有“贵且能打”的装备。于是搜刮会改变后续战斗能力，背包越满，撤离与继续深入的选择也越有分量。

洞窟深度提供明确的目标和奖励梯度。例如铁矿可能要到第二层、金矿到第三层、钻石到第四层才能取得；更高级的种子和装备也可随深入逐步出现。这些只是描述方向的例子，具体层数、资源位置和产量尚未确定。未来可以加入剧情或小任务，为玩家每次下洞提供“这次想带回什么”的目标。

## 合作方式

多人是**纯 PvE 合作**，参考《杀戮尖塔 2》的多人模式：朋友处于同一局、走同一条路线、面对同一组敌人；各人操作自己的牌，出牌效果随操作发生，队伍共同完成战斗与探索。游戏没有玩家之间的战斗。

战利品包含各人的个人奖励与额外的公共物资；公共区域可以出现更高价值的东西。玩家可以把自己的物品主动分享给队友，也可以争取公共物资。物品最终由谁带走，会影响谁的背包、卡组和撤离所得。具体领取与分配流程以后再定。

## 当前试想，尚待试玩决定

- 洞窟大约四层，每层出现一到两次是否撤离的抉择；准确长度和撤离频率尚未定。
- 胸挂、背包、保险箱可能通过**卡牌进入战斗的时机**体现区别：胸挂物品牌最快可用，背包物品牌从第二回合洗入抽牌堆，保险箱物品牌更晚进入。第二回合洗入不保证第二回合抽到；这些都是原型规则，之后根据实际手感修改。
- 保险箱可能用于保护少量物品，使其在死亡后仍能带回。容量、可放物品及战斗作用尚未定。
- 跑刀、重装等不同成本的进洞方式，以及装备等级与风险收益的关系，留待经济和战斗原型验证。

## 现阶段的设计判断

这套游戏最值得优先验证的，不是农场项目有多少、洞窟有多少敌人，而是一个反复出现的决定：**我已搜到想要的东西；它改变了我的牌组，我还要不要带着它继续深入？**如果这个决定在单人和朋友合作时都有趣，战斗、搜刮、撤离与家园成长就能形成同一个玩法核心。
