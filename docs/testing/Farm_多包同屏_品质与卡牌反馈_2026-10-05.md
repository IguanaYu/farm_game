# 多包同屏、五档品质与卡牌反馈

2026-10-05 接续尸体搜刮和首页单人试玩入口，落实本次试玩反馈。

## 玩家可见变化

- 同一具尸体的武器、护具、腰包、背包使用两列布局，同时展开；每个区域都有搜索／暂停按钮。所有区域在 1280×800 和 1024×640 窗口内完整可见，无须切换区域分页。不同尸体仍可通过尸体选择框切换。
- 搜索以整件物品实际占格为单位。品质越高，圆环越久；空格快速检查。未搜索的物品保持中性轮廓，不提前显示名称、图标和品质颜色。
- 已揭晓装备的背景、边框、图标、详情、背包与拖动预览使用同一品质色；战备箱按实际实例品质显示。品质在装包、转移、保存和下一场牌组中保留。
- 卡面直接显示“来自：铜短剑／木盾／小药水”等来源，来源条与边框使用该件物品的品质色。牌组快照保存来源定义和品质，远端镜像也能显示。
- 自身牌单击或数字键一次即可生效。单人模式只有一个合法友方目标的掩护、包扎也直接自用；合作掩护仍须选择自己或队友。攻击牌保留选敌人与拖动出牌。
- 成功结算后显示出牌轨迹、护盾扩散、斩击火花、治疗光环、抽牌与状态特效，配合较大的浮动文字。仅选牌、能量不足、等待远端确认时不提前播放效果。覆盖层不阻挡操作，动画结束自动清理；减少动态效果设置下保留静态淡出反馈。
- 首页“单人卡牌试玩”顶部新增“品质”选项：默认随机掉落，也可指定白／蓝／紫／金／红。切换后恢复初始装备并重开本场，以便直接比较颜色和搜索速度；仍为独立临时试玩，不写农场存档。
