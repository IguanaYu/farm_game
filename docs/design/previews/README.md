# 多场景与空间交互设计预览

保存日期：2026-10-03。当前版本：v0.4。

- [完整设计稿](../Farm_多场景与空间交互_设计稿_v0.4.md)：场景构图、自然物体入口、交易与对话、多好友拜访流程，以及后续 Godot 实施建议。
- [可点击预览](farm-scenes-v0.4.html)：独立 HTML 文件，用浏览器直接打开；无需启动 Godot 或服务器。
- [可编辑预览源稿](farm-scenes-v0.4.fragment.html)：与对话中 v0.4 可点击稿相同的 HTML 片段，包含场景绘制、界面样式及演示交互。独立预览由此源稿导出；修改源稿后需同步更新独立预览。
- [截图与验证记录](../../../screenshots/design_multiscene_2026-10-03_v04/)：各场景、地址簿、不同好友的院子与小屋，以及 102 组布局检查记录。

进入预览后，点商店门廊进入杂货铺；点石阶去洞窟营地；点信箱、小桥或邻里房屋选择朋友，再点院子里的房子进屋。门、窗与院门承接返回流程。

预览使用临时演示数据，不接入真实游戏存档、联网资产或好友消息。预览文件包含页面与脚本，核心场景交互可以离线查看；装饰图标的显示可能依赖网络资源。
