# 尸体搜刮实施与验收

2026-10-05。用户授权实施后，完成“点尸体 → 打开格子 → 圆环搜索 → 发现物品 → 装包”的闭环，覆盖单人、本地合作和线上服务端代码。Windows 包已重新导出；公网服务没有在本次工作中部署。

## 玩家体验

整场战斗胜利后进入清理战场，点击各敌人的遗骸打开搜索。按用户同日补充，未知物品现在用实际占格合并成中性轮廓：盾牌搜索区块为 2×2，短剑为 1×3，圆环位于整块中央；完成后整件物品揭晓，尺寸保持一致。位置与尺寸可以预先看见，名称、图标、品质及属性仍隐藏，未知轮廓不可选择或领取。已发现物品可以立即装包，拖动时按 R 旋转。关闭后回到战后场景，切换或暂停中断当前搜索，已发现结果保留。离开前提示未搜索区域和未取走物品。

普通野怪有独立身体区域，同场多个敌人不复制整场奖励。第一层第三个行进节点的战斗分支加入骷髅巡逻兵，路线提示“带着武器和两个包的骷髅巡逻兵”。它持铜短剑、穿皮护腕，战后分武器、护具、腰包、背包搜索；腰包和背包当前是搜索区域，包本身不是可穿戴装备。

新尸体物品发现后均可领取，携带容量限制收益；装入对应容器后继续沿用第 1／2／3 回合入牌规则。合作时物品全队一份，搜索结果共享，不同区域可以并行，同一区域只允许一人搜索。满包失败不消耗掉落，腾出空间后能继续拿。宝箱、采集及已裁定的旧局节点保留原规则。

待试玩初值：物品 850 ms，空格 110 ms；普通遗骸 2×3，大型遗骸按实际占格扩大；骷髅武器 1×3、护具与腰包 2×2、背包 3×4。新增敌人生命、意图、配装和收益需在试玩后调整。

## 实现与恢复

`CorpseLootGame` 在节点首次裁定时固定内容与布局，分配唯一实例 ID，保存已搜索格、揭晓与领取状态。恢复局档不重抽，中断未完成的格。搜索完成由权威时钟判断，客户端圆环只展示进度；未知物品不能领取。主机和专用服务的初始快照、常规推送、回执及重连欢迎都使用过滤投影，不传未发现物品定义、实例或属性及随机种子。新增 `unknown` 与搜索 `footprint` 只包含位置和实际朝向尺寸，支持旋转后的 3×1 长条；旧局无需重生成物品。

领取转移原物品实例，保留品质和剩余使用次数；先验证实际容量与精确放置，再标记来源已取走。重复领取和跨成员重复领取被拒绝。断连释放搜索占用并推送快照；客机重连清除丢失回执造成的等待状态。线上搜刮动作等待实际服务回执及镜像，不把“已发送”当成完成。

界面新增 `CorpseLootStage` 与 `CorpseSearchGrid`，复用现有 `ExpeditionLootPanel` 的详情、玩家携带格子、整理和动作通道。选择源物品时保留原拖动控件，避免鼠标按下后重建控件导致拖拽丢失。
