# 菜单主题 · 2026-10-12

目标：减少通用绿白菜单和蓝绿金探险界面的既视感，建立与「农场＋探险」相关的视觉特征，延续已精简的文字与统一战场布局。

## 视觉

| 用途 | 色值 |
| --- | --- |
| 深色背景 | `#201b25` |
| 桑葚紫面板 | `#302735` |
| 按钮与浮起层 | `#403443` |
| 陶土橙主操作 | `#df947a` |
| 米白纸页、卡面 | `#f1eadf` |
| 鼠尾草绿友方状态 | `#b1c5a0` |

- 首页保留农场场景，改为暖光与低饱和遮罩；前景使用深紫菜单。标题加入种子／嫩芽印章，副标题缩短为「耕种 · 探险 · 组队」。卡牌试玩用陶土色突出。
- 首页、战斗设置、营地和路线共用原生矢量纸页角标、折角与细线。面板与按钮采用对角不同圆角，悬停、按下、键盘焦点和禁用状态分别可辨。
- 战场、手牌区、搜刮格子统一到深紫底色；卡面保留明亮米白，选择时偏暖。普通洞窟、铁根、晶脉仍有各自底色。
- 主菜单设置与配装使用米白纸页、灰紫边线、深色文字。原有物品品质色与分类色保留，避免主题替换影响识别。
- 重开、首页和试玩选项仍收在齿轮菜单内；没有增加常显操作文案。

主题集中在 `ExpeditionUI`，共享浅色控件集中在 `LifeUI`。存档、战斗规则与联网协议未改。

对比入口：[Cozy Grove 官方页面](https://cozygrovegame.com/)、[Cult of the Lamb 官方素材入口](https://influencers.devolverdigital.com/cult-of-the-lamb)。项目的配色与种子印章由当前题材和试玩反馈确定。

- `d58_prep_ui_smoke`：23 项通过，装备槽、容器、预设与整理。

- `d32_coop_play_ui_smoke`：双人战斗、设置、搜刮、投票与撤离通过。
- `d54_menu_live_input_smoke`：主菜单及农场暂停的真实输入断言通过，退出码 0。该脚本点击退出时终止仍在等待帧的测试协程，退出日志有清理提示；verbose 日志包含两条 `GDScriptFunctionState` 和测试持有的 `FarmGame`，不计为无警告退出。
