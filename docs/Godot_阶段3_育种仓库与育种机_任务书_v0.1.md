# 小小农场 · 阶段 3 任务书：属性育种、仓库与育种机（v0.1）

编写日期：2026-09-29。适用工程：Godot 4.6.1，Windows，项目根目录 `E:\gpt\godot\farm`。本文自包含：接手本阶段的开发者只需本文、仓库代码和两份规则文档即可开工。

## 项目速览

点击式种田游戏，玩家不控制小人移动，直接点击地块和建筑操作。单人首版核心循环：**选种 → 播种与照料 → 现实时间成熟（离线也生长）→ 收获作物和新种子 → 育种或复制 → 比较报价出售 → 购买、扩地与升级 → 下一轮**。多人玩法不在首版范围内。

单人首版共 6 个阶段：1 最小闭环 → 2 种植照料与成长（浇水、施肥、经验、两种植物） → **3 育种仓库育种机（本任务书）** → 4 每日客人与经济 → 5 体验与素材 → 6 回归与交付。

4. **随机与离线结果可复现。**每粒种子的抽取结果在收获结算时一次生成并保存；读档、反复开关面板、重复结算不得重抽。育种机离线产出按上次在线时刻与读档时刻结算一次并保存，重复读档不重复产出。测试用固定随机种子与受控时间，不修改系统时钟。
5. **每项功能同时有可玩入口和可核对结果。**新增场景节点用明确名称和路径，避免靠无筛选的 `get_children()` 猜节点身份。素材原件在 `art/lowpoly/`，运行时副本在 `assets/`，映射见 `assets/stage1_manifest.json`。
6. **交付报告**写明：修改文件、实现的规则、未定规则所用的可调初值、自动测试命令及结果、手动试玩步骤及结果、旧档迁移结果、未解决问题。验收失败项如实标记。

## 开发内容

### 1. 种子词条与属性分配

- 每粒种子有唯一 ID、植物类型、最多 **4 条词条**。
- 三项属性：**含水量、纤维含量、色泽**。一轮作物的基础属性总点数 = **播种时种地等级 + 该植物等级**（阶段 2 已保存快照）。
- 六种词条效果：

| 词条类型 | 档位（逐档晋升，不可跳档） | 显示品质分 |
| --- | --- | --- |
| 水分/纤维/色泽 保底 | 1 点 → 2 点 → 3 点 | 1 / 2 / 3 分 |
| 水分/纤维/色泽 倾向 | +10% → +30% → +50% → +100% | 1 / 2 / 3 / 4 分 |

- 分配顺序：**先满足所有保底词条**（即使保底合计超过可分配点数也要满足），剩余点数按三项权重随机分配。默认权重各 100；倾向词条把自身权重从 100 加到 100×(1+百分比)。例如只有"水分倾向 +100%"时权重为 200:100:100，水分抽中率 50%。每个剩余点独立抽取。
- 同一效果只保留**最高档**（不叠加低档与高档）；不同效果可共存（如"水分倾向"与"水分保底"同时出现）。
- 种子**显示品质只取最高分的单条词条**，不求和；无词条种子品质为 0。品质只用于快速识别，不代替阅读词条。

### 2. 后代词条生成（每粒独立判定）

每粒新种子按以下顺序独立判定（同一地块同一轮的 2～3 粒可以各不相同）：

1. **亲本词条继承**：对亲本的每条词条分别判定保留。保留率：使用保种肥料（该轮播种时生效）**80%**；未使用 **30%**。
2. **保留后的升档**：每条成功保留的词条单独判定升一档。升档率：

| 词条 | 保种肥料 | 不使用 |
| --- | --- | --- |
| 三项保底 1→2 / 2→3 | 8% / 3% | 4% / 1% |
| 三项倾向 +10→+30 / +30→+50 / +50→+100 | 8% / 8% / 3% | 4% / 4% / 1% |

3. **全新词条**：按该种子**实际保留后的词条数**判定是否新增一条（0/1/2/3 条时概率 **70% / 30% / 10% / 1%**）。变异肥料（该轮播种时生效）在对应概率上**加 10 个百分点**（80%/40%/20%/11%），不保证必出。成功只新增 **1 条**，从该种子**尚未拥有**的六种效果中等概率抽取；已有 4 条即达上限，变异肥料也不突破。

- 判定顺序（继承 → 升档 → 新词条）必须可用固定输入复算。
- 种子结果保存后不因读档重抽；收获时一次生成并写入存档。
- 保种、变异肥料只改变上述概率，不改变阶段 2 的分数加成规则。

### 3. 仓库

- 分**作物区**和**种子区**；每区容量随仓库等级：1/2/3/4 级为 **60/120/240/480 格**（可调初值）。
- 不同地块的作物批次**分开存放**（即使属性相同）；同一批按数量占一个作物格。
- **属性与词条完全相同**的种子可叠放，每格最多 **99 粒**；不同则分格。
- 仓库满时收获产生"**待领取结果**"：显示整理、出售（默认 1.2 倍）或回收入口，不得静默丢失作物或种子，也不得重复领取。腾出空间后领取一次成功，再次领取无新增物品。
- 仓库升级交易本阶段接入：1→2 级 **1,200 金币**，2→3 级 **15,000 金币**，3→4 级 **17,000 金币**（试算初值；商店等级折扣阶段 4 统一接入）。开局仓库为 1 级。
- 提供仓库内**逐粒种子比较、保留、播种选种**入口。**不能再沿用阶段 1 的"总是取种子列表第一粒"作为玩家操作**；播种必须让玩家选定具体种子（或提供明确的默认策略入口并说明）。

### 4. 育种机（复制种子）

- **种地 2 级**解锁，从购买商店买到；首次购买 **15,000 金币**（1 级），1→2 级 **17,000 金币**，2→3 级价格**待定，用占位配置并在报告标注**。
- 三个等级：复制一粒需 **60 / 55 / 50 分钟**，机内容量 **8 / 12 / 16 粒**（可调初值）。
- 同一时间只锁定 **1 粒种子**作为模板；**原种始终保留在仓库**；复制品与模板词条**完全相同**。
- 每个模板按**种子 ID** 分别保存未满一周期的进度；切换模板后再切回，进度恢复。
- 关闭游戏期间计时继续；重新进入时按离线时长结算产出，**离线跨多个周期只产到机内容量上限**，满了暂停复制。
- 副本先积存在机内，玩家手动采摘；采摘时种子区已满则领取失败（明确提示），副本继续安全留在机内、机内数量不减少。种子仓库满不使育种机停机。

### 5. 界面

- 可读的种子与作物批次仓库、种子选择界面（展示每粒全部词条与品质）、育种机界面（模板、进度、机内数量、容量）、待领取结果界面。
- 播种选种时能看到种子词条，播种后消耗对应 ID 的种子。
- 规则参数（保留率、升档率、新词条率、容量、周期、价格）集中在配置处，不散落。

## 验收步骤与通过条件

- 同一块地的 2～3 粒新种子逐粒有独立 ID 和独立抽取结果；种子词条影响批次属性分配，跨存读档稳定；继承→升档→新增的顺序可用固定输入测试复算。
- 在 0/1/2/3/4 条词条、保种肥料、变异肥料、重复效果的边界下：均不超过 4 条、不跳档（+10 直接到 +50 或保底 1 直接到 3 都不允许）、不在同一效果上重复添加已有同类效果。
- 作物区或种子区刚好满一格、刚好满仓、多出一批时，待领取结果仍在；卖出或回收腾出空间后领取一次成功，再次领取无新增物品。
- 选择模板 A 运行不足一周期，切到 B 再切回 A，A 的进度不丢；离线跨多个周期只产到机内容量上限。满仓时领取失败，机内数量不减少；模板原种始终可在仓库找到。
- 从仓库逐粒选种播种消耗正确种子；一键收获与逐块收获产出种子一致。
- 阶段 1、2 测试全部通过；旧档迁移不丢失物品。

## 规则速查（本阶段数值，均为可调初值）

| 项 | 值 |
| --- | --- |
| 属性基础总点数 | 播种时种地等级 + 植物等级 |
| 词条上限 | 每粒 4 条；同效果只留最高档 |
| 保底分配 | 先满足保底（可超总点数），剩余按权重随机（默认 100:100:100） |
| 倾向权重 | 基础 100 × (1+百分比)；+100% 即 200 |
| 继承保留率 | 保种 80% / 普通 30%（逐条独立） |
| 升档率 | 保底：保种 8%/3%，普通 4%/1%；倾向：保种 8%/8%/3%，普通 4%/4%/1% |
| 新词条率 | 按保留后条数 70%/30%/10%/1%；变异 +10 个百分点 |
| 每地每轮新种子 | 2 或 3 粒，各 50%，逐粒独立 |
| 仓库容量/级 | 作物区、种子区各 60/120/240/480 格；种子叠放 ≤99/格 |
| 仓库升级价 | 1,200 / 15,000 / 17,000 金币 |
| 育种机 | 种地 2 级解锁；60/55/50 分钟一粒；容量 8/12/16；购入 15,000，1→2 级 17,000，2→3 占位 |
