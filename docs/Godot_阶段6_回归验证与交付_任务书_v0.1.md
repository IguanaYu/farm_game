# 小小农场 · 阶段 6 任务书：回归验证、平衡与 Windows 交付（v0.1）

编写日期：2026-09-29。适用工程：Godot 4.6.1，Windows，项目根目录 `E:\gpt\godot\farm`。本文自包含：接手本阶段的开发者只需本文、仓库代码和两份规则文档即可开工。

## 项目速览

点击式种田游戏，玩家不控制小人移动，直接点击地块和建筑操作。单人首版核心循环：**选种 → 播种与照料 → 现实时间成熟（离线也生长）→ 收获作物和新种子 → 育种或复制 → 比较报价出售 → 购买、扩地与升级 → 下一轮**。多人玩法不在首版范围内。

单人首版共 6 个阶段：1 最小闭环 → 2 种植照料与成长 → 3 育种仓库育种机 → 4 每日客人与经济 → 5 体验与素材整合 → **6 回归验证与交付（本任务书）**。**阶段 6 通过前，不把"单人首版"标为完成**；若导出包未完成或只在编辑器中试玩，阶段 6 不通过。

## 本阶段目标

证明完整单人循环**可靠**、经济节奏**可接受**，并交付普通玩家可运行的 Windows 版本。

## 开发内容

### 1. 全量回归（阶段 1～5 全部验收项）

逐项核对各阶段任务书的"验收步骤与通过条件"，重点补测以下边界：

- 空仓与满仓：仓库满时收获、领取、整理、出售、回收的全路径；待领取结果不丢不重。
- 肥料与浇水时段边界：恰好到期、时段交界前后、成熟时刻操作、覆盖多轮短周期、未到期替换被拒。
- 跨北京时间日期：23:59:59 / 00:00:00 交界、跳过多日、锁客人与锁公式次日生效、系数逐日重抽。
- 升级发生在某轮收获时：本轮等级加分不受影响，下一轮生效。
- 同一按钮连续快速点击：购买、出售、收获、领取均不产生额外收益或重复结算。
- 存档中断恢复：写入失败/中断后可用备份恢复；不出现半档丢失物品。
- 旧档迁移：v1～当前各版本样例逐个升级读入，物品、金币、地块不丢失。
- 离线育种机达到容量上限：只产到上限、满仓领取失败时副本留机内。

### 2. 模拟与平衡

- 用固定随机种子和调试时间推进，模拟**早期 1～3 天**及**中期数十轮**；记录收益、花费、升级等待轮数、育种进展。
- 与玩法文档目标对照，主要锚点：
  - 经济节奏：前期约 **1 天能负担任意 2 项一档购买/升级**；基础项完成后约 **2～3 天负担 1 项二档**（一档/二档清单见玩法文档第 6 节）。
  - 基准毛收入：六块地、默认 1.2 倍、不计额外加分约 **3,888 金币/天**（第二种植物未解锁时 3,528）。
  - 育种节奏：保种肥料下水分保底 1→2 约 **2～3 轮**、2→3 约 **4～6 轮**。
  - 报价调试目标：种地与该植物均 2 级、合适客人时最终倍率约 **1.5 倍**。
- 数值调整必须写明依据（哪条模拟结果偏离目标），并更新配置与测试期望；不做无依据的顺手调整。

### 3. 真实流程验证与调试清理

- 用**真实关闭游戏、重新启动**的流程检查离线种植、遭遇、每日客人和育种机（不能只用规则层模拟代替）。
- 清理或限制调试入口（如 F9 立即成熟、调试时间推进）：确保正式包不可用或明确隐藏，方式写入报告。
- 编写玩家操作说明（可放进 README 或游戏内帮助）与已知限制（如设备时钟可被修改影响离线结算、单人版无云存档）。

### 4. Windows 导出包

- Godot 4.6.1 编辑器导入无阻断错误后，导出 Windows 可运行包（导出模板、图标、版本信息自定，方式写入报告）。
- 保留源工程与可编辑素材（`art/lowpoly/` 原件不删除）。
- 在导出包里：从新档完整试玩一轮主循环；并从旧档（编辑器产生的真实档迁移）试玩，确认存档路径与结果与编辑器版一致。

## 必须交付

- 自动测试结果（全部测试通过）与人工回归记录。
- 经济与育种模拟报告（配置、样本量、与目标对照、调整依据）。
- 最终操作说明与已知限制。
- Windows 可运行包及导出方式说明。
- 最终已知问题清单：每项含复现方法、影响、是否阻断主循环。

## 最终通过条件

- 新档能持续进行"播种/照料 → 收获/育种 → 比价出售 → 购买升级 → 再播种"，直到**育种机与每日客人都实际参与循环**。
- 连续存读档不丢物品、不重复结算；所有待领取产出都有明确去处；无阻断主流程的脚本错误。
- 编辑器运行与 Windows 导出包的主要规则和存档结果一致。
- 经济与育种模拟结果落在目标区间，或偏离项均有已记录的数值调整依据。
- 导出包完成并实际试玩通过。
