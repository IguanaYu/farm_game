# 农场 UI 信息分层（2026-10-02）

本轮调整农场 HUD、播种、照料、收获、仓库、商店、集市与育种机。深绿主操作、浅色卡片与弱边框替代原有厚重面板；世界模型与洞窟独立面板沿用现状。

## 默认显示

- 种子：作物图标、名称、数量、生长时间、品质及全部词条标签。四词条自动换行，不靠截断省字。
- 作物：数量、单个分数、水分/纤维/色泽三个属性，以及实际售价。
- 商店：种子、肥料、设施分栏；商品双列卡片，购买按钮显示规则层计算的折扣价格。
- 照料：倒计时、进度条、各浇水时段状态、可执行操作。每秒更新状态，不重建操作按钮。
- 收获：作物、新种子、默认售价、经验优先；得分计算、新种子词条与本轮经历折叠。
- 集市：客人价格并排比较，最高客人报价高亮。默认按钮始终出售整批，客人按钮使用所选数量；两者明确标注。每日公式与锁定配置放在折叠区。
- 待领取：数量和领取入口常显；展开后仍可逐批出售、逐粒回收。
- 育种机：模板词条、进度、容量、领取及升级，复制规则按需展开。

## 信息与规则

所有售价、品质、分数、时段、育种状态继续来自 `FarmGame` 与原有定义。没有修改 `scripts/domain/` 或存档结构。展开状态在本次运行内保留，界面刷新不会强制收起。

资源数量用图标表示，悬停可查看名称；等级经验用进度条与悬停数值表示。状态提示显示 6 秒，悬停可读全文。种子品质仍取最高单条词条分，展示层不合并为另一套规则。

萤果与岩芽菜仍使用项目原有胡萝卜占位图标；本轮未制作新的美术素材，也未调整洞窟战斗与战备界面。
