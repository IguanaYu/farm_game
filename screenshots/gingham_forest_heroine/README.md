# 照片参考造型实机

两种可切换造型：红格帽（第二张参考照片）、星星发饰（第一张参考照片）。六张动作卡随主角一起变化。

- `01_in_game.png`：红格帽实机与首手五张卡。
- `02_next_hand.png`：下一手，包含敲击。
- `03_character_and_cards.png`：红格帽主角与六张卡的设计板。
- `04_small_window.png`：1024×640 布局。
- `05_star_alternative.png`：同一战斗状态切到星星造型。
- `06_star_character_and_cards.png`：星星主角与六张卡的设计板。

入口：首页 → 森林预览 → 进入森林试玩 → 攻击动画样稿，右上角切换“红格帽 / 星星发饰”。

`capture_cute_forest_hero.gd` 验证默认角色、五张卡纹理、切换前后状态不变、恢复红格帽、攻击复制与取消、小窗口，共 18 项。
