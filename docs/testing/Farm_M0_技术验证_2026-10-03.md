## 3. Godot 4.6 API 坑（本轮实测确认，供后续阶段）

1. `OS.get_ticks_msec()` **已移除** → 用 `Time.get_ticks_msec()`。
2. `MultiplayerPeer` 连接状态只有三常量：`CONNECTION_DISCONNECTED/CONNECTING/CONNECTED`；**无 `STATE_*`、无 `CONNECTION_FAILED`**——握手失败表现为回到 DISCONNECTED。
3. `WebSocketMultiplayerPeer` **无 `get_peer_list()`**：用 `peer_connected/peer_disconnected` 信号自维护在线表；收包走主 peer `get_packet()/get_packet_peer()`，定向发包 `set_target_peer()+put_packet()`。
4. 本工程警告即错误：`var x := <Variant 返回值>` 会以"从 Variant 推断"报解析错误，须写 `var x: Variant =`。
5. godot-sqlite 的 `query_with_bindings(sql, bindings)` 至少要 2 个参数；无绑定时用 `query(sql)`。
6. **官方导出二进制禁用路径覆盖**：`--script` 与位置参数场景在导出包里不可用（`disable_path_overrides`），本机编辑器二进制可用所以本地测不出——服务端入口改 `boot.tscn` 按 `--server` 参数分流。
7. 导出包里后台进程 + 参数解析：用户参数含无值开关（`--server`）时不能按固定步长配对解析，统一按名取值；`_ready` 内切场景必须 `call_deferred`（否则 remove_child 报错）。
8. 远端 `pkill -f <名>` 会连承载命令的 `bash -c` 一起杀（命令行含同样字符串），须用 `^\./farm_server` 锚定；SSH 通道里 `nohup ... &` 后台进程要 `< /dev/null` 并避免其后接长命令，否则通道 EOF 挂起。
