# 卡面视觉设计原则与六张森林卡重设计提案

日期：2026-10-21。状态：研究与设计约束；已据此制作射击、守护铃、烟幕三张视觉样稿，尚未批量替换卡面。本轮保留已确认的主角，不把角色立绘和战斗卡插图视为同一种交付。

## 用户明确提出的两项基础原则

主角固定使用用户再次贴图确认的草帽小姑娘：棕色双辫、浅黄草帽、粉色丝带、绿色背带裙。对应 `screenshots/cute_forest_girl/03_character_and_cards.png`。卡面改变构图，不改变角色身份；射击里的米色袖口、烟幕里的草帽与双辫也须一致。

1. 一眼能看出图中是什么、在做什么。
2. 卡牌有明显区分度；缩小后至少可以分辨攻击与防御。

当前六张卡虽然单独看可爱，但同时采用居中、正面、全身人物和近似背景，主要差异只有小道具与小幅手势。在实际手牌中，大形、明暗、主体位置基本重复，因此不能作为合格的功能卡面继续批量生产。

## 一手资料中的设计思路

以下是作者本人或开发者的说明；后面的项目规则是基于这些资料提出的应用方案，并非声称两款游戏采用同一套攻防编码。

### 从牌的内容出发构思，而不是先套人物模板

《杀戮尖塔》卡牌及事件画师 Anailis Dorta 介绍，制作时会根据卡名或描述先做 2–3 张草图，想法不够强时再进行限时调研、探索不同姿势或设计。她也说明，各种游戏美术可以有不同细节程度，仍然通过类似的情绪与形状语言保持统一。

来源：[Anailis Dorta 与 Bruce Brenneise 访谈，2025-05-27](https://www.moregamesplease.com/art-in-boardgames/2025/5/27/anailis-dorta-amp-bruce-brenneise-slay-the-spire-art-in-board-games-76)。

### 视觉主角服从卡牌表达的对象

炉石美术总监 Ben Thompson 在讲解 Poisoned Blade 时明确要求，武器卡应该清楚地呈现为一件可辨认的武器，焦点不要转移到持有它的角色或周围法术。这是针对武器卡的具体制作要求，不能简单推广为所有卡都只能画物品；可借鉴的是按卡牌内容决定视觉焦点。

来源：[GameSpot 对 Ben Thompson 的直接访谈，2015-08-02，Poisoned Blade 部分](https://www.gamespot.com/articles/the-glorious-art-behind-hearthstones-the-grand-tou/1100-6429343/)。

### 先用缩略草图解决大形、明暗与画面意图

炉石插画师 Cole Eastburn 的制作说明强调，缩略草图首先用来解决大的明暗分组、表情、气氛和画面故事；草图阶段不追求完成度。他也建议方案探索要提供不同的情绪与表达，不能只是同一个姿势换角度。

来源：[Cole Eastburn，How those epic Hearthstone cards are made，Thumbnailing / Different options 部分](https://www.creativebloq.com/3d/how-those-epic-hearthstone-cards-are-made)。

### 卡牌作为游戏信息载体，需要限制装饰干扰

Ben Thompson 的官方设计复盘说明，复杂材质和结构曾抢走数值的注意力，变化繁多的卡框也曾让牌桌难读。最终团队围绕数值、卡名、卡图建立清晰的信息层级。

来源：[暴雪官方，Hearthside Chat — Art with Ben Thompson，2014-02-25](https://hearthstone.blizzard.com/en-gb/news/13023802)。

### 用最终屏幕尺寸判断是否读得懂

Mega Crit 的 Casey Yano 复盘过早期角色在屏幕小尺寸下的误读，包括姿势、持物方法和表情。该段谈的是角色精灵，并非专门讨论卡牌；对我们的启发是验证时必须回到实际显示尺寸。

来源：[Mega Crit 官方，The Neowsletter — October 2024，On Aesthetics Driving Game Design](https://megacrit.com/news/2024-10-02-neowsletter-issue-3/)。

## 在本项目中的具体应用

### 将统一风格和重复构图区分开

保留圆润造型、低饱和森林色、暖木色道具和可爱的世界观。人物是否出现、景别、方向、主体位置、动作和背景色块应随卡的作用改变。小姑娘可以只出现手、侧脸、背影，或完全不出现。

角色是世界观线索，不是每张卡必须占据中心的内容。攻击牌可以用夸张的箭头、武器近景和清楚的接触点保持可爱，同时传达冲击；防御牌用包覆、阻挡和稳定的轮廓表现保护。

### 建立多种攻防识别线索

- 卡图：优先读出武器/效果及其作用，给它最大的轮廓或最强的明暗对比。
- 构图：攻击倾向向外发力、穿出画面的方向；防御倾向围住主体、拦住冲击的结构。这是项目的设计倾向，不是无例外的几何规则。
- 类型标记：在固定位置用清楚的攻击/防御图标和短标签辅助识别。
- 配色：可用暖色局部强调攻击、冷色局部强调防御，作为辅助，不要求整张卡统一染色，也不单独依赖颜色。
- 卡名、费用和数值位置保持一致。品质与攻防类型要使用不同的信息位置，避免一个卡框颜色同时承担两种含义。

当前 UI 已按牌类给费用底色着色，但卡框主要跟随物品品质，画面又几乎同色同构。只靠费用角标的差异不足以弥补卡图的相似性。

### 六张牌的构图任务

| 卡牌 | 主要视觉任务 | 与其他牌的区分 |
| --- | --- | --- |
| 射击 | 放大的弓弦、离弦的一支箭和明确飞行方向；人物可只保留拉弓的手 | 弓的弧线与单支细长箭；有发射感 |
| 突刺 | 枪尖/矛尖近景向前刺出，手臂或身体局部带出力量 | 最明显的长斜线与近大远小，不能只是人物举着一根矛 |
| 强射 | 弩的近景、粗壮的一支弩箭与更强的冲击视觉 | 与射击区分为厚重、蓄力；不画多支弹道或穿透多个目标，以免暗示不存在的多段/穿透规则 |
| 敲击 | 祭铃杖处于砸下并接触目标的瞬间，接触点和冲击形状清楚 | 主体是正在打击的杖头；不能与守护铃同为平静地举铃 |
| 守护铃 | 保护形状占据主体，明确隔开被保护者与外部冲击；铃体现来源 | 稳定、包覆的轮廓，保护区域一眼可见；不靠细小的盾图标补救 |
| 烟幕 | 大团烟雾包围主体、缓冲外部冲击，人物为次要轮廓 | 柔软、扩散的团块，和守护铃较整齐的保护轮廓区分；不暗示尚不存在的隐身/闪避系统 |

### 工作顺序与验收

1. 先做射击、守护铃、烟幕三张，分别覆盖攻击、明确保护、另一种防御表达。
2. 每张先画 2–3 个有明显景别/构图差异的黑白草图，不先细化表情和服饰。
3. 按实际手牌缩图检查：当前 1280×800 下卡牌约 148×216，插图约 128×80；另用 64×40 插图做额外压力测试。小窗口再回到实际游戏确认，尺寸以控件最终布局为准。
4. 遮住卡名、费用、效果文字，只看图能否说出主要物体/动作，并区分攻击和防御。
5. 转灰度检查：即使去掉颜色，类别和同类卡之间仍应有轮廓、明暗或构图差异。
6. 将三张随机混排，判断是一组能快速认出的游戏卡面，而不是三张同构角色肖像。
7. 小图通过后再细化配色、可爱细节、材质和角色表情，最后补足其余三张。

三张样稿与实际卡图尺寸/灰度对照位于 `screenshots/card_readability_v04/`，原生 SVG 位于 `assets/art_studies/card_readability_v04/`。捕获脚本临时将纹理用于真实手牌，对照同一战斗快照；未替换原有卡牌资源映射或修改规则。另按用户贴图要求，将主角恢复到已确认的草帽双辫小姑娘，并同步卡面局部形象与游戏包。自动检查只验证资源、截图和状态不变，识别效果由人工判断。
