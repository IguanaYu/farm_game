# 小小农场应用图标

低多边形白菜与一块农田组成的透明背景图标，与游戏现有的低多边形素材风格呼应。

- `farm_icon.png`：内置 imagegen 工具生成的原始 PNG，供 `project.godot` 的 `config/icon` 使用。
- `farm_icon.ico`：由原始 PNG 转换而来，保留透明背景，包含 16、24、32、48、64、128、256 像素七种尺寸，供 Windows 导出图标使用。

生成日期：2026-10-01。生成方式：内置 imagegen，未使用 API/CLI。
