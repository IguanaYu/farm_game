# 小小农场 · 阶段 2 收获算例（固定输入，可手工核对）

生成方式：`tests/stage2_worked_example.gd`，固定随机种子 20260930、播种时间 1759000000，全部时间受控输入。该脚本属于交付物，可重复运行得到相同输出。

计分规则（每作物，全部整数运算）：

```
每作物分 = 基准分 + 等级加分 + 波动加分 + 浇水加分 + 肥料加分 + 遭遇加分
等级加分 = 基准 × (种地快照等级-1 + 植物快照等级-1) × 5%      # 播种时快照
波动加分 = 基准 × 波动百分比（0~10%，播种时预抽）
浇水加分 = 基准 × 10% × 完成的有效时段数                       # 水壶 1 级
肥料加分 = 基准 × 20%（本轮生长期内施肥区间有交集即完整生效）
遭遇加分 = 每条 +10 / +40 / +70 分（播种时预抽，多条相加）
默认售价 = floor(每作物分 × 5 个作物 × 1.2 ÷ 100)
```

## 算例一：白菜（新档、等级 1、浇满 1 个时段、基础肥料）

固定输入：播种 t=1759000000；t+300 浇水（唯一时段）；t+600 施基础肥料（未到期覆盖整个生长期）；t+1200 成熟即收获。预抽结果：新种子 2 粒，波动 5%，遭遇 1 条 +40。

| 构成 | 计算 | 每作物加分 |
| --- | --- | --- |
| 基准分 | 20 分钟植物固定 | 200 |
| 等级加分 | 种地 Lv.1 + 植物 Lv.1，0×5% | +0 |
| 波动 | 200×5% | +10 |
| 浇水 | 200×10%×1 段 | +20 |
| 基础肥料 | 200×20% | +40 |
| 遭遇 | 1 条 +40 | +40 |
| **每作物合计** | | **310** |

整批 310×5 = 1550 分。默认售价 = ⌊1550×1.2÷100⌋ = ⌊18.6⌋ = **18 金币**。经验 +20（种地与白菜各一份），新种子 2 粒。收获面板"这一轮的经历"有 5 条记录（播种、浇水、施肥、遭遇、收获）。

## 算例二：胡萝卜（暂名）（种地 2 级 + 植物 3 级快照、浇满 2 个时段、金克拉肥料）

固定输入：播种 t=1759000000（此时种地经验 120 → Lv.2，胡萝卜经验 840 → Lv.3，均按播种时快照）；t+600 浇第 1 时段、t+4200 浇第 2 时段；t+300 施金克拉肥料；t+7200 成熟即收获。预抽结果：新种子 3 粒，波动固定 7%，遭遇 2 条 +40、+10。

| 构成 | 计算 | 每作物加分 |
| --- | --- | --- |
| 基准分 | 2 小时植物固定 | 1200 |
| 等级加分 | (2-1 + 3-1)×5% = 15% → 1200×15% | +180 |
| 波动 | 1200×7% | +84 |
| 浇水 | 1200×10%×2 段 | +240 |
| 金克拉肥料 | 1200×20% | +240 |
| 遭遇 | +40 +10 | +50 |
| **每作物合计** | | **1994** |

整批 1994×5 = 9970 分。默认售价 = ⌊9970×(1.2+0.2)÷100⌋ = ⌊139.58⌋ = **139 金币**（阶段 4 起，金克拉批次的默认出售同样 +0.2；阶段 2 当时按 1.2 倍为 119，此文档已按新规则更新）。经验 +120（种地与胡萝卜各一份），新种子 3 粒。该批次记录 `sale_multiplier_bonus = 0.2`（金克拉标记，默认出售本阶段仍按 1.2 倍，报价算法在阶段 4 使用）。

## 边界速查

- 浇水时段边界（2 小时植物）：第 59:59 仍属第 1 时段，60:00 整进入第 2 时段；同时段重复浇被拒绝且不留记录。
- 肥料到期边界：肥料恰好在播种时刻到期（`expires_at == planted_at`）则本轮无加分；到期前完成播种的轮次都完整加分。
- 重复结算：波动、遭遇、新种子数在播种时一次性预抽保存；读档、反复打开面板、重复收获都不重抽、不重复产出。
