# 小小农场 · 阶段 5 任务书：玩家体验与素材整合（v0.1）

编写日期：2026-09-29。适用工程：Godot 4.6.1，Windows，项目根目录 `E:\gpt\godot\farm`。本文自包含：接手本阶段的开发者只需本文、仓库代码和两份规则文档即可开工。

## 项目速览

点击式种田游戏，玩家不控制小人移动，直接点击地块和建筑操作。单人首版核心循环：**选种 → 播种与照料 → 现实时间成熟（离线也生长）→ 收获作物和新种子 → 育种或复制 → 比较报价出售 → 购买、扩地与升级 → 下一轮**。多人玩法不在首版范围内。

单人首版共 6 个阶段：1 最小闭环 → 2 种植照料与成长 → 3 育种仓库育种机 → 4 每日客人与经济 → **5 体验与素材整合（本任务书）** → 6 回归与交付。

## 进入本阶段的前提（以实际代码为准）

阶段 1～4 已交付完整单人循环：两种植物、照料、经验、育种与仓库、育种机、每日客人、拆批出售、扩地到十块与各类升级。本阶段**不新增规则系统**，重点是可理解性、反馈与素材落地；改动以界面、文案、素材、引导为主，涉及规则参数的调整需在交付报告中单列。若发现代码与本文描述不符，以代码为准并说明。

## 通用开发约定（对所有阶段生效）

1. **一次只接一个阶段。**先读材料、读代码、读测试，再列出本阶段具体改动清单；通过本阶段全部验收后才算完成。
2. **规则层负责裁定。**本阶段不改规则逻辑；若为展示需要小改规则层，须在报告中单列并跑全部回归测试。
3. **保护旧档。**若涉及存档结构变化，把 `FarmGame.SAVE_VERSION` 升级并做迁移；阶段 4 存档样例必须能升级读入。素材占位不改变规则 ID 或存档结构。
4. **不引入阻断性占位。**缺失素材可用明确的占位图，但不得出现不可操作或误导玩家的入口。
5. **每项功能同时有可玩入口和可核对结果。**新增场景节点用明确名称和路径，避免靠无筛选的 `get_children()` 猜节点身份。素材原件在 `art/lowpoly/`（`.gdignore` 阻止 Godot 扫描），运行时副本在 `assets/`，映射见 `assets/stage1_manifest.json`；新增运行时素材要更新映射。
6. **交付报告**写明：修改文件、素材清单变更、问题修复记录、自动测试命令及结果、人工试玩记录（含试玩者反馈原话要点）、未解决问题。验收失败项如实标记。

## 本阶段目标

让玩家**不看设计文档**，也能知道下一步做什么，以及一粒种子和一批作物为什么有价值。

## 开发内容

### 1. 素材盘点与场景整合

- 完成外部素材盘点，更新 `assets/stage1_manifest.json` 资产映射，逐项标注：可直接用、需修正、缺失、授权待确认。
- 把以下元素放入一致的立体农场布局：地块成长阶段（发芽→成熟各阶段可视区分）、第二种植物、设施（商店、仓库、育种机）、肥料、六位客人形象、环境装饰。
- 缺失素材使用**明确占位图**（统一占位风格、标注"占位"），不改变规则 ID 或存档结构。
- 素材导出流程沿用 `art/lowpoly/EXPORT_GUIDE.md`。

### 2. 操作反馈与信息展示

- 地块：悬停高亮、选中反馈、成熟提示（可收获状态一目了然）、可操作反馈（可浇水/可施肥的时段状态）。
- 显示生长进度、当前植物的有效浇水时段（已完成/未完成）、肥料剩余时间。
- 仓库：筛选（按植物、品质、词条）与种子词条对比视图。
- 收获面板与报价面板：展示数值来源（基准分、各项加分、公式、倍率），玩家能看懂"这个数是怎么来的"。
- 满仓、育种机满、解锁条件不足：给可理解的提示和可操作入口（如"仓库已满 → 去整理/出售/回收"按钮）。

### 3. 文案与引导

- 为正向遭遇编写正式文案，与实际 **+10 / +40 / +70** 档位一致（不同档位文案有可感知的强弱差异，替换阶段 2 的占位文案）。
- 加入**首轮操作引导**：引导新玩家完成"播种 → 等待/浇水 → 成熟收获 → 出售 → 再播种"的第一次循环；引导可在设置中跳过。
- 六位客人、两种植物、四种肥料、各类词条的名称与说明文案定稿（占位名清理）。
- 声音、动画和额外装饰只在核心交互清楚后再加入；不影响验收。

## 必须交付

- 完整的运行时素材清单与更新的资产映射（含标注）。
- 关键界面截图（农场全景、收获面板、仓库、报价面板、育种机、引导流程）。
- 首轮操作引导。
- 问题修复记录与人工试玩记录。
- 全部阶段 1～4 自动测试通过的结果。

## 验收步骤与通过条件

- **新玩家测试**：找未读过玩法文档的试玩者，从新档独立完成首次播种、成熟后收获、出售和再播种；记录卡住的步骤并修到能独立完成。
- 试玩者能在界面上找到某粒种子的词条、说出为什么保留它；能看懂同批作物对不同客人报价为何不同（数值来源可见）。
- 六块地、十块地、满仓、批量出售、种子比较这几个场景中：关键按钮可见可点、文字不遮挡、地块点选不误触；没有阻断循环的占位入口。
- 遭遇文案与分数档位一致；引导可完成、可跳过、不重复打扰。
- 在项目真实窗口比例下的人工试玩记录，覆盖上述全部场景。
- 阶段 1～4 自动测试全部通过；旧档（各阶段样例）迁移试玩正常。
