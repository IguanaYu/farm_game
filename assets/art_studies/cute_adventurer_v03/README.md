# 照片参考小姐姐 · 主角与动作卡样稿

按用户提供的两张照片提取可见外观特征，保持现有圆润几何画风。同一位主角有两种可切换造型：红白格宽檐帽、黑蝴蝶结、深色长卷发、灰蓝上衣与深色领口；以及粉白星星发饰、深色齐肩卷发、薄刘海、米白开衫与小金色吊坠。只保存重画的 SVG，构造源不依赖照片路径。

六张卡由同一份主角 SVG 构造生成，姿势、道具和辅助符号分别对应射击、突刺、强射、敲击、守护铃、烟幕。卡面无费用/文字，仍由真实战斗 UI 绘制。

- 主角：`assets/characters/farmer_cute.svg` 为红格帽默认形象；`farmer_star.svg` 为星星发饰。保持 farmer 主题 ID 与共享 2D 控件。
- 卡牌：本目录六张 SVG 为红格帽版，`star/` 为星星版。“攻击动画样稿”右上角可以同步切换主角与卡面；卡牌规则与费用保持已有样稿定义。
- 构造源：`python tools/build_cute_forest_hero.py`；主角与卡牌共享同一个 `hero(pose)`。
- 实机与两种造型设计板：`screenshots/gingham_forest_heroine/`；早期版本截图保留在原目录。
- 捕获与视觉接线检查：`tests/capture_cute_forest_hero.gd`。

足底仍在 200 单位画布的 y=188，主角按 2 倍密度导入，保持现有落地阴影与攻击轴点。原有整片前冲、箭矢、受击和减少动态效果设置继续工作。切换造型只替换纹理，不重开战斗或修改战斗状态。
