## 实现的规则

1. **词条**：六种效果（三种保底 3 档、三种倾向 4 档），每粒最多 4 条、同效果唯一；品质 = 最高单条分；种子按"植物+词条集合"签名叠放 ≤99/格。
2. **后代判定**（每粒独立，顺序固定可复算）：继承（保种 80%/普通 30% 逐条）→ 保留词条各判一次升一档（保底 8%/3%、倾向 8%/8%/3%，普通减半，满档不可再升）→ 按保留后条数判新词条（70%/30%/10%/1%，变异 +10pp），从子代未拥有的效果中抽、恒为 0 档；亲本未继承的效果允许被重新抽到（视为全新词条）。
3. **属性分配**：批次属性总点数 = 播种快照（种地+植物等级）；先满足保底（可超预算），剩余按 100:100:100 权重加倾向百分比逐点分配；结果存入批次 `attributes`（阶段 4 报价使用）。
4. **仓库**：作物区/种子区各 60/120/240/480 格；批次各占 1 格；仓库满时收获产出进"待领取"（不丢失、不重复领取），支持领取/按默认价出售/按 5 金币回收；升级 1,200/15,000/17,000。
5. **育种机**：种地 2 级 + 15,000 金币购买；60/55/50 分钟一粒、容量 8/12/16；1→2 级 17,000，2→3 占位（界面显示"价格待定"）；单模板、原种留仓库、副本词条与模板完全相同；按种子 ID 保存各模板进度，切换不丢；离线跨多周期只产到容量上限，满了暂停不积累；机内满时采摘要求种子区有空间，否则失败且机内不减。
6. **播种**：按具体种子 ID 消耗（`plant_seed`）；按种类快捷播种保留为兼容入口（内部同样定位到具体种子）。
7. **存档 v3**：v2 → v3 迁移补 warehouse_level/breeder/pending/parent_traits/attributes；旧无词条种子与旧批次照常使用、出售、种植。
