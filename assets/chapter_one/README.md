# 苔冠森林 · 简洁几何插图

2026-10-20。按用户确认延续当前运行中游戏的简洁几何风。造型与配色参照 `scripts/ui/expedition_art.gd` 和 `scripts/ui/expedition_ui.gd`：低饱和色、圆形与多边形、圆头线段、点状眼睛、少量平面明暗。现有手绘古道概念图继续作为独立参考，未覆盖。

| 目录 | 件数 | 尺寸 | 用途 |
| --- | ---: | --- | --- |
| `backgrounds/` | 5 | 1280×640 | 五区场景背景；中心留出角色与交互空间 |
| `enemies/` | 23 | 256×256 | 透明敌人全身插图，含 5 个区域强敌 |
| `props/` | 43 | 256×256 | 透明搜索对象插图，与搜索模板一一对应 |
| `items/` | 36 | 256×256 | 透明物品插图，包含 31 件新物品及 5 件复用定义 |
| `cards/` | 16 | 320×200 | 新增来源牌插图；不烘焙牌名、费用、品质和规则文字 |

合计 123 件独立 SVG。保留原有玩法 ID；资源与玩法定义分离。物品和卡牌的数值、掉落、战斗效果仍按 P1～P8 推进，此次图片接入不打开森林出发开关。

资源经 `ChapterArtRegistry.resolve()` 查找，前缀为 `bg.forest_ch1.`、`enemy.`、`prop.`、`item.` 和 `card.`。已导入纹理返回 `ready=true` 与 `texture_path`，可用 `ChapterArtRegistry.texture(spec)` 获取 `Texture2D`。未知 ID、未导入或缺失的纹理继续回退到原有形状参数。五区、敌人、搜索物、物品及来源牌均在主菜单「测试功能」→「森林预览」中展示；数值未接入的项目明确标注开发阶段。

三色史莱姆以叶片／火焰／冰晶区分，哥布林以弓箭／剑盾／长矛／药筐区分；首领分别增加灰鬃、根棺、巨铃、头目羽饰和菌冠。人物比例保持当前游戏的圆头和短四肢。

生成源码为项目自带的 `tools/build_forest_art.py`，使用 Python 标准库构造 SVG，不依赖图像生成服务、外部模型或栅格图片。再生成命令：

```powershell
python tools/build_forest_art.py
```

该命令仅重建本目录的 123 件 SVG 和 `manifest.json`。资源 ID、中文名称从 `ChapterOneDefs` 提取；实际造型在生成器中维护，新增内容不能仅靠登记自动获得新造型。手工调整图片时应同步修改生成器，避免下次生成覆盖。`manifest.json` 记录资源 ID、名称、类别、路径与 SHA256。

共用 `ExpeditionArt` 已支持背景、敌人、搜索物、物品、卡牌纹理；实际战斗卡牌优先使用牌面专图，其次使用来源物品插图。背包、掉落、物品详情使用登记物品插图。未实现的新定义不会提前写入存档或掉落表。

2026-10-21 新增游戏内入口：「测试功能」→「森林预览」→「进入森林试玩」。五区背景、23 种敌人外观与 43 个物件可切换查看；战斗、战后搜索、装包和携带装备续战使用现有独立卡牌试玩逻辑。该入口明确标注沿用骷髅规则，敌人数值、物资规则和正式章节进度不变，临时数据不落正式农场或局档。
