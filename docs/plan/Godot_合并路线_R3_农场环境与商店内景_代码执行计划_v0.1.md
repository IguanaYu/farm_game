# 合并路线 R3：农场环境与商店内景 代码执行计划 v0.1

编写日期：2026-10-04。状态：**已完成**（d48 18/18；全量回归 55/55）。

依据：[合并路线图](Godot_合并路线图_联网与多场景_v0.1.md) R3 行；[多场景与空间交互设计稿 v0.4](../design/Farm_多场景与空间交互_设计稿_v0.4.md) §4（农场）、§5（商店）、§11 标准 1~4。

## 1. 目标与非目标

**出口**（路线图 R3）：

> 稿 §11 标准 1～4：无裸露地台截面；一次点击进商店；买完卖完不出场景；交易规则全保留（39 命令不动）。

**非目标：**
- 洞口营地（R4）、拜访（R7）。
- 真实视角/光照调优与实机视觉验收（用户做）；本轮以 headless 结构断言 + 现有回归护栏。
- 不改任何交易规则/UI 面板逻辑——商店内景承载现有 hud 面板（柜台→商店、客人→集市、篮子→选择后集市）；设计稿 §5 的"篮子→客人分步流"是 UI 重设计，随本轮仅做场景承载，面板流程下一轮打磨。

## 2. 农场环境（稿 §4）

1. **连续地形**：EarthBase/GrassTop 放大数倍延伸出镜头外（尺寸 ×4，中心偏移）；新增林带（环形低多边形树列，复用 TREE_MODEL 多排）与远景山影（大尺寸低细节锥体，环境层不参与点击）。消灭"矩形盒子+纯色背景"的漂浮感；三个桌面分辨率下四边不露地台截面（d48 结构断言：地台半径 ≥ 镜头视口对角线）。
2. **入口实体化**（全部可点击，接 router/现有入口）：
   - 商店门廊：雨棚（绿白条纹用双色 box 交替拼）+ 门口菜筐（小 box 堆叠，复用设施色）+ 门（发光边框 box）；点击=现有 shop 建筑点击（router 切商店）。
   - 上山石阶：东南角一列灰色台阶 box（3~4 级，附提灯=发光小柱）；点击=现有 cave 入口（打开探险营地面板，R4 前仍走 hub 面板）。
   - 邻里信箱+小桥：西侧溪流（蓝色窄长 box 沿 z 轴）+ 石桥（灰 box 拱面近似）；信箱（柱+箱+小旗）；点击信箱/桥=提示"好友拜访将在后续版本开放"（R7 前占位，不接死）。
3. **待开垦地**：未购地块不再隐藏，改为草地色低矮地块（无作物位、不可点击）表达"待扩建"位置感。
4. 客人站位从门口栅栏前移到店廊侧（稿 §2"客人进店"的过渡：本轮先挪到门廊旁，正式三人进店随商店内景）。

## 3. 商店内景（稿 §5，替换 R2 占位间）

`ShopStubLocation` 升级为 `ShopInterior`（仍在 farm_world 内程序化构建，注册到 router 的 "shop"）：

1. **空间**：约 10×8 暖木地板 + 三面墙（去前墙去顶的浅俯视切墙内景）；柜台在后墙前；左右货架两排（分层 box）；委托台角落。
2. **镜头**：进店时相机切换为低近俯角（新 Camera3D 属于商店地点，进入时 current=true，离店还原农场相机——router on_enter/on_leave 钩子驱动）。
3. **三人客人**：从 farm 门廊移入店内前景并排站位（复用 GUEST_MODELS 与 `_refresh_guest_models`，站位表随地点切换）；点击客人=现有 `hud.open_market()`（保持 M2 全部交易规则）。
4. **功能入口**：柜台=商店面板（`hud.open_shop()`）；种子/肥料货架=商店面板同入口（本轮承载，下轮拆分）；门=router.go_back()。
5. **FarmLocation 客人站位**：保留空位（农场门口不再站人——稿 §2"原来站在农场栅栏前的三位客人移到这里"）；`_on_guest_input` 移除/改提示。

## 4. 测试（d48 + 回归）

`tests/d48_farm_shop_scene_smoke.gd`：
1. 结构断言：FarmLocation 下存在雨棚/石阶/信箱/小桥/溪流节点；ShopInterior 下存在柜台/货架/三客人位/门；客人模型与当日 guest_ids 一致。
2. 切换断言：进店后商店相机 current、农场相机 not current；客人位随 market 快照刷新。
3. 交易规则回归：进店状态点击柜台路径调用 `hud.open_shop()`（面板可用性断言，不动 39 命令）；离店返回 farm 后 game 实例不变（d47 语义复检 2 次）。
4. 三个分辨率（1440×900/1280×800/1024×640）下地台覆盖断言：正交相机 size 换算视口四角射线均命中地面扩展层。
5. 全量回归：现有 54 项零变化（world_picking 已兼容 FarmLocation；客人站位迁移后 d33 等不受影响——它们不依赖 guest slot 位置）。

## 6. 风险

| 风险 | 对策 |
| --- | --- |
| 地形放大后地块/建筑相对比例失衡 | 尺寸参数集中为常量，逐步放大并记录；d48 断言用射线覆盖而非精确尺寸 |
| 程序化雨棚/石阶视觉粗糙 | 属实机打磨范畴（用户验收）；结构先对，配色沿现有色板 |
| 客人站位迁移破坏现有点击流 | 保留 `_on_guest_input` 处理器（店内站位绑定同逻辑）；d33 手动调 open_market 不受影响 |
| 相机切换与 HUD 层级冲突 | 商店相机仅切 current 标志；HUD 在 CanvasLayer 与相机无关 |

## 8. 实施记录

### 2026-10-04：R3 全部落地

- **R3-a 农场环境**：地台扩展 48×38.5（三分辨率正交角点射线覆盖，无裸露截面）；林带（周界树列 +meta 标记）与五座远山；商店门廊（绿白条纹雨棚+菜筐+可点击踏步）；上山石阶+提灯；邻里溪流+石桥+信箱（点击占位提示 R7）；未购地块改为待开垦草桩（十块地恒可见，未购不可点击）。
- **R3-b 商店内景**：ShopStubLocation 升级 ShopInterior——暖木地板+三面切墙、后墙柜台+发光沿、左右分层货架+委托台、前景三客人（模型随当日 guest_ids 刷新，点击=今日集市面板）、回程门；内景正交相机（size 7.2 低近俯角）经 router enter/leave 钩子切换 current。
- **关键坑**：物理射线不理会节点可见性——隐藏的内景货架会挡农场点击/射线（world_picking 实测）。落地为 `_set_location_physics`：非当前地点的 CollisionObject3D 碰撞层清零（切回恢复原层）。

**偏差**：稿 §5 的"篮子→客人分步交易流"未做 UI 重构（计划 §1 已声明：本轮仅场景承载，面板流程随后续打磨轮）；客人短话气泡同上。
