# 森林新卡实机样稿

入口：首页 → 森林预览 → 进入森林试玩 → 攻击动画样稿。

本次样稿把旧手牌换成六张森林新卡，使用已有 SVG 插图，按内容设计 v0.1 §10.2 的费用、目标和数值实际出牌：射击（1费/6伤害）、突刺（1费/6伤害）、强射（2费/13伤害）、敲击（1费/4伤害）、守护铃（1费/5格挡）、烟幕（1费/4格挡）。射击、强射触发箭矢。

10 张固定样稿牌组（六个种类），首手展示五种新卡，第二回合可看到敲击。可结束回合、查看牌堆、获胜搜刮和重开。敌人仍使用样例规则；未开放正式森林出发。这些定义只由独立试玩的 CombatGame 子类提供，未修改正式 CardDefs 或存档。
