# 育种测试模式（2026-10-13）

主菜单右下角新增“测试功能：开 / 关”。默认关闭，在当前启动中保留选择。开启后可以继续独立测试进度或开始新测试，农场右下角显示倍率与“作物立即成熟”。

- 时间倍率：1、60、300、1200，默认 60；只加速农场时钟，不改变动画、点击、音效或战斗速度。
- 植物生长、浇水时段、肥料有效期、育种机和每日集市共用测试时钟，育种概率与词条规则保持原有逻辑。
- 1200 倍示例：白菜约 1 秒自然成熟，一级育种机约 3 秒复制一粒；育种面板原位更新进度、产量与领取按钮。
- 首次“继续测试”复制本地正式进度，保留种子词条。随后读写 `user://farm_test_save_v1.json`，包含虚拟时间与倍率。新测试覆盖前确认，旧测试档自动备份。
- 返回主菜单或退出保存测试进度，菜单和关闭游戏期间不推进测试时钟；关闭开关后恢复正式进度。主菜单与农场内的组队入口在测试模式中关闭，线上上下文始终使用服务器时钟。
- Windows 发布构建也提供测试按钮和测试模式下的 F9 成熟快捷键。
