## 2. M4 服务端硬化（O01～O04/O07 的自动化切片）

1. **健康检查（O02）**：`ping` 扩展为携带 `online/rooms/runs/errors/uptime` 的健康包（未认证可用）；`--status` 子命令读库输出 JSON 摘要后退出（守护外诊断）。
2. **备份与恢复（O03）**：`--backup <dir>` 子命令——`sqlite3 backup` 语义（godot-sqlite 无 backup API：以 `VACUUM INTO ?` 生成一致快照，M0 已验证路径）；备份文件名带时间戳；`tools/restore_verify.py`（隔离环境打开备份+断言 schema/账户数——开发机可跑）。
3. **维护门控（O04）**：`--maintenance-file <path>`：文件存在 → 新 hello/req 拒 `maintenance`（错误码入 §3.3 表外延：`maintenance`），已有会话收 `bye(maintenance)` 后断开；跑中房间/局不强制中断（提示后自便）。
4. **守护（O02）**：`tools/farm-server.service`（systemd 单元模板：Restart=on-failure、ExecStart 带参数占位）+ 部署说明文档；`--dev` 公网守卫已有。
5. **错误计数**：server_main 收 `internal_error/tx_failed` 计数进健康包（O06 铺垫）。
