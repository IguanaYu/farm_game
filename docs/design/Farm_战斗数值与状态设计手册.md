# Farm 战斗数值与状态设计手册

版本：2026-10-23。后续新增或调整卡牌、装备来源、敌人和战斗状态，统一按本文设计。实际运行规则详见项目 `docs/design/Farm_五种基础状态_运行规则_2026-10-23.md`；既有逐牌数值见首轮卡牌调整表。

## 费用与品质

| 定位 | 1费参考 | 设计目的 |
| --- | --- | --- |
| 初始攻击／防御 | 5攻击／5格挡 | 留出装备成长空间 |
| 初始混合 | 3攻击＋自己3格挡 | 提供灵活性，分别指定效果目标 |
| 标准 | 8攻击／8格挡 | 所有纯数值牌的共同参照 |
| 高质量示例 | 13攻击／12格挡 | 直接体现好装备的收益 |

2费纯数值牌先参照16，再考虑来源、获取阶段、附加效果和手牌消耗。高质量牌不强制附带负面效果。品质不统一乘倍率；每张牌单独定价。抽牌、状态、治疗和攻击防御不可直接等价相加。持续能力须评估剩余战斗回合，多段攻击须逐段计算力量收益。

## 敌人压力

轻击以7～10点、重击以15点作首轮参照。8格挡面对7点全挡、面对10点掉2血；两张8格挡挡住15点。初始5格挡应对15点需要3费，高质量12格挡可选择花1费掉3血或追加防御。

多段按总量归档：5×2是10点压力；力量逐段增加。多敌人按同一玩家本轮承受的总伤害评价。同时检查玩家是否还有能量进攻，不把每只敌人单独称为轻压力。敌人生命与行动频率根据击杀回合和受伤情况调整，不全表乘倍率。

## 五种状态与计算

| 状态 | 规则 |
| --- | --- |
| 易伤 | 受到攻击伤害×1.5；层数延长持续时间，不增加倍率 |
| 虚弱 | 造成攻击伤害×0.75；层数延长持续时间，不增加倍率 |
| 中毒 | 持有者行动开始先受当前层数伤害，再减1；绕过格挡与所有攻击修正 |
| 力量 | 每段攻击的基础值＋层数，本场持续 |
| 敏捷 | 每次普通格挡＋施放者层数；给队友格挡也用施放者敏捷，本场持续 |

攻击＝floor(max(0,基础攻击＋力量)×虚弱倍率×易伤倍率)，中间不取整；最后抵扣目标格挡。普通格挡＝max(0,基础格挡＋施放者敏捷)。例：8攻＋2力量同时虚弱易伤得到11；抵扣5格挡后扣6血。7攻同时虚弱易伤得到7。

正数层数重复施加相加，0层移除。行动开始清旧格挡、结算中毒并立即处理倒地或胜负，毒死者不行动。行动结束易伤、虚弱各减1；合作模式在共同阶段结束时各减一次。战斗结束全部清除。

卡牌按效果数组顺序执行；先易伤后攻击会增强当前一击，先攻击后易伤不会。敌人在攻击后施加1层玩家易伤，会在下一玩家阶段结束时消失，通常不能增强敌人下轮攻击。希望覆盖下一轮时需配置2层或重新安排施加顺序。

## 每张新牌的设计登记

必须记录：稳定ID、名称、费用、目标、按顺序列出的效果、单效果目标、出牌去向、定位、来源装备、来源牌数、获取阶段、画面短文案、完整说明和相对8点锚点的理由。旧ID不因数值改变随意改名，以兼容已有快照。

混合牌明确“打谁”“谁获得格挡”。多段明确每段与段数。能力明确持续时间和重复获得限制；首轮力量／敏捷样例牌采用1费＋2层、本场移除，暂不推定完整能力区已实现。

普通格挡不得写成永久减伤。设计文案、卡面、目标预览、敌人意图和战斗日志必须表达同一规则；新机制须同时更新正式试玩与森林样稿入口。预览不得改变真实状态或随机数。

## 验证与调参流程

1. 登记费用、定位、来源及效果顺序，给出可手算预期。
2. 使用固定种子和固定牌序，在7／10／15点场景比较初始、标准、高质量三档。
3. 记录总掉血、击杀回合、进攻能量投入、连续遭遇损耗；检查多敌人总压力和好装备的可感知收益。
4. 验证虚弱1层有效后消失、中毒3→2→1、力量逐段加成、敏捷归属、混合目标、死亡中断、快照往返和合作不重复扣层。
5. 检查最小1024×640窗口的卡面、状态悬停、连击转向与伤害预览。再运行战斗专项和项目整体回归，保存实际日志。
6. 真人试玩后更新数值与观察记录。自动策略获胜只能说明可复现，不能据此宣布已平衡。

调整本手册时记录日期、原因、受影响牌与敌人、前后算例和验证结果。历史提案与本文冲突时，以本文费用参照及当前运行规则为准；新增机制不能仅更新文档而宣称已落地。

## 2026-10-24：第二批森林情境卡

新增十张独立试玩定义，登记见 [第二批规则与画面](Farm_森林情境卡第二批_规则与画面_2026-10-24.md)。沿用五种基础状态和 8 点费用参照，正式物品与章节出发开关维持原状态。图鉴中的全部十六张卡均有情境插图；新增十张可在“新卡试玩”入口体验。

- **净化**：移除所选存活友方的易伤、虚弱和中毒全部层数，保留力量、敏捷；无负面状态时仍可使用，消耗费用但不会凭空获得收益。不会救起倒地者。共享效果入口、预览和战斗日志使用同一移除规则。
- **部分穿透**：先按原有力量、虚弱、易伤公式算出最终攻击值 D；P=min(D,max(0,穿透值))；格挡抵消=min(目标格挡,D−P)，生命损失=D−格挡抵消。穿透部分不消耗格挡，也不额外增加伤害。5 攻／穿透 3 遇到 8 格挡，扣 3 血、消耗 2 格挡；遇到 0 格挡，仍只扣 5 血。中毒继续采用独立规则，不受穿透修正。
- **火与冰的首轮范围**：火囊与火把使用直接攻击伤害；冰囊使用攻击后虚弱。灼烧、独立寒冷、冻结和跳过行动尚未实现，不在卡面说明或预览中承诺这些效果。
- **补给试玩**：一次性补给使用“本场移除”，不消耗农场库存，也未宣称已完成来源物品耗尽后的关联牌清理。正式装备来源数量与获取阶段单独记录在第二批表中，保留给后续章节接线。

验证覆盖新牌实际结算与预览一致、队友净化不误清出牌者、穿透与攻击修正、治疗上限、移除去向、状态结算及最小窗口。上述初值仍需真人体验来评价节奏与强度。
