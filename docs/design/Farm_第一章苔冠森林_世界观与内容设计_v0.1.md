日期：2026-10-19。状态：讨论稿；名称、数值、配方与路线均为提案，尚未实现或试玩验证。

本稿将用户提出的森林、神殿、废弃宝塔及另外两个地点，组织为**同一森林章节内的五个区域**。重点是形成“在哪里遇到什么敌人、搜索什么东西、拿到什么物品、物品带来什么牌”的关系，而非先拆开发任务。

阅读时可先看第 1～8 节的世界与区域，第 9～13 节作为物品卡牌关联的配套草案查阅。精确费用和数值不作为本轮世界观讨论的前置决定。

## 1. 世界的底色

世界暂名「树庭边境」。玩家生活在大森林边缘的农庄，与附近的商人、猎人、药师和其他农户往来。森林是木材、草药、蜂蜜和珍稀种子的来源，也埋着一个失落文明留下的道路、神殿和塔楼。

过去，这里的「守林教团」负责维护地下水路与具有魔力的树根网络，合称「根脉」。他们在神殿保存种子、祭祀先人，在层叠的宝塔上观测林雾、鸣钟报信；农耕、护林和仪式原本属于同一种生活。

教团衰落后，后来的伐木者与盗掘者破坏了部分根脉。泉水、树脂和菌群吸收逸散的魔力，出现了元素史莱姆与异常繁殖的菌泽；失去维护的守卫把闯入者当成敌人。商道断续废弃，强盗占领营地，哥布林趁机捡拾、抢夺人类的工具和食物。

玩家最初进入森林，是为了寻找能种活的珍稀种子、制作材料和失踪商队的物资。带回的物品逐渐让村民拼出根脉失衡的原因，最后引导玩家进入神殿深处。第一章的目标是**恢复一处根脉、重新打开一段旧商道**。危机改善的是森林的一部分，野兽、匪患和其他未修复遗迹仍然存在，支持后续重复探索。

整体气质是有生活感的奇幻冒险：林缘明亮温暖，深处幽静危险；遗迹略诡异，但不依赖血腥恐怖。重要视觉符号统一为叶形纹样、树脂封蜡、铜铃、白麻布与盘绕的根须。

### 1.1 为什么森林里有木乃伊和宝塔

- **木乃伊**：守林者以干燥药草、白麻布和树脂保存先人遗体，安置在神殿石棺中。根脉失衡后，部分裹尸守卫重新行动。造型突出叶纹布条、琥珀树脂与苔痕。
- **神殿**：曾兼有祭祀、种子储藏、泉水分配和安葬守林者的用途。因此棺椁、种匣、蓄水池和药草供品可以自然共存。
- **宝塔**：同一教团修建的多层巡林与镇雾设施，木石混建，带层檐、铜铃和观测台。其建筑细节与神殿相同，仍保留用户希望的“废弃宝塔”辨识度。
- **史莱姆**：天然凝胶生物会吸收周围物质。绿色吸收草药与树液，红色聚集在旧炉与火晶残渣附近，蓝色生于冷泉。能力和掉落物跟栖息地一致。
- **哥布林与强盗**：哥布林擅长回收、拼装和偷袭；强盗依赖商道、仓库与现成兵器。双方也争夺物资，通常不会混编成一支队伍。

### 1.2 可以遇到的非敌对角色

林间药师收购药草、教授制剂；巡林猎人提供狼踪与巢穴情报；行脚货郎交换补给；受困伐木工提供营地入口线索；少数中立哥布林愿意以铜片交换蜂蜜。角色用于让森林呈现出生活与利益关系，不额外增加第一章必做支线。

一次出发建议游历古道与一个目标区域，约 8～12 个节点作为后续试玩初值。深入区域前和区域收尾安排可识别的撤离机会；无需每局走完五区。玩家通过不同地点发现的碑文、旧图或村民情报，累计了解神殿深处的位置；线索记在日志中，不以反复携带钥匙物品占包为主要门槛。

### 3.2 敌人与遭遇

普通组合：剑盾哥布林＋弓手、两只森林狼、单只或同色双史莱姆。跨群体同场需要争食、追猎等明确事件理由，常规遭遇优先使用同一生态群体。

区域强敌「灰鬃头狼」用嚎叫预告下一轮扑击，并使同伴形成同步进攻压力；玩家可以先削减小狼，也可以准备格挡迎接扑击。头狼不无限召唤，额外战利品也不随战斗拖延增加。

### 4.2 敌人与遭遇

「裹尸守卫」移动迟缓，交替缠击与自护；「封棺祭司」为守卫加固或进行有次数上限的修复；「穴蝠」以低血量、多段攻击和虚弱干扰配装。蓝史莱姆出现在有泉水的区域，不与每一组木乃伊固定绑定。

章末首领「根棺祭司」与神殿主棺、根须和铜铃相连。其循环为修复棺甲、摇铃蓄势、根须重击；玩家能从意图提前准备。火能有效压制其修复，但普通攻击、易伤和持续伤害也能完成战斗，避免把某一种元素变成通关钥匙。

### 5.2 敌人与遭遇

「木甲守卫」以格挡蓄力后重击；「铃影」是残留在铃器中的守护术式，干扰抽牌节奏或施加虚弱，优先采用后者控制首章复杂度。穴蝠栖息于断层，冷泉附近可少量复用蓝史莱姆。相同史莱姆保留原有能力，不额外制造一套“塔内蓝史莱姆”。

区域强敌「空铃守塔人」交替使用守塔格挡、敲铃干扰与蓄力重击。多铃齐响只是意图表现，不在初版同时扩充多个可攻击部件。

### 6.2 敌人与遭遇

斧匪负责高伤害蓄力，弩匪交替射击与装填，绳网猎匪施加虚弱、为同伴制造爆发机会。匪徒占据的屋内不混入一群被其放任活动的野兽；红史莱姆主要在炉区或营地外围独立遭遇。

区域强敌「劫路头目」带一名护卫，先指挥集火再亲自劈砍；其药品库存有限。玩家能从尸体搜到对应武器、药物和携带货物，掉落品质可以简陋，但不让“举着斧头的敌人”只掉无关法杖。

### 7.2 敌人与遭遇

「腐木蛛」使用中毒与短暂虚弱；「菌寄行尸」是被菌丝驱动的旧遗骸，攻击慢、毒性强；蓝绿史莱姆在此共享生态。初版不另外增加紫、黑、金等颜色，以免颜色很多、决策却重复。

区域强敌「菌冠母体」交替释放孢子和保护菌膜。它的菌体护卫为固定数量，不无限生成可反复搜刮的新尸体。稀有奖励倾向孢种、凝胶与可制作防具的材料。

## 9. 物品与关联卡牌目录

### 9.1 与现有规则的衔接

保留项目的实体物品逻辑：**物品面积为 N 格，提供 N 张来源牌；同一张牌可以占多个牌位。**装备在装备槽时不占容器空间，但仍按其物品尺寸生成牌；卸下后需要对应背包空间。

当前代码基线为装备槽第 1 回合、胸挂第 2 回合、背包第 3 回合洗入来源牌；保险箱内物品牌不入堆，保护资格仍遵循白名单。该口径见 `scripts/domain/expedition_baseline.gd` 与 `docs/plan/Farm_三栏背包与装备槽_实施记录_2026-10-06.md`，不沿用更早的胸挂首回合方案。

货物、材料、种子默认提供负担牌；少数有魔力的资源可以兼具战斗作用，靠稀有度和占格控制，避免所有值钱货物都同时强化牌组。所有一次性物品共享来源使用次数：任一来源牌耗尽实体后，其余关联牌一起清除。

下表中的尺寸与牌构成为可核对的提案。新武器、防具与现有装备槽的类别映射在后续实施时明确；本稿不增设饰品槽，工具、羽饰、号角等使用现有容器。

### 10.3 新状态的最小规则

- **灼烧 X**：目标下次行动开始时受到 X 点无视格挡的伤害，随后清除。同一目标只保留最高强度，重新施加不累加；首章初值最高 2。短爆发与中毒的逐步衰减区别开来。
- **寒冷**：目标下一次行动阶段的第一段攻击伤害减 2，最低为 0，该行动结束后清除；即使该次只防守也清除。多次施加仅刷新，不叠加、不跳过整个行动。对玩家即下一回合第一段攻击减 2、回合结束清除。
- **中毒、易伤、虚弱**：沿用现有基线，不因森林换一套算法。
- **章内元素交互**：火可抑制特定敌人的一次修复，作为写在意图与说明中的额外优势；不设计所有火伤都对所有木质敌人翻倍的隐藏规则。该交互可在基础三色怪通过试玩后再加入。

## 11. 三条完整的获取链

1. **搜到蜂蜜，决定吃还是带回。**处理蜂巢 → 拿到 1 格蜂蜜块 → 下一战按存放位置加入「食蜜」 → 使用后恢复与抽牌，实体消失；没用则可带回做蜂蜜料理。
2. **从敌人的能力得到对应战术。**遭遇蓝史莱姆 → 被寒冷降低进攻效率 → 战后搜到蓝凝胶囊 → 下次用「投掷冰囊」减轻头狼或斧匪的攻击压力。掉落数量在遭遇生成时确定，不随它释放冰招的次数增加。
3. **捡到贵重物，撤离变得更有吸引力。**神殿宝箱 → 得到 2×2 古银器 → 放入背包后，第 3 回合洗入 4 张负担牌 → 玩家在高价货物、下一场战斗与背包空间之间取舍。可以换掉低价值材料腾位置，也可以放弃货物继续深入。

## 13. 刷新与复用原则

1. **地点限制物资池。**鸟巢偏羽饰与种子；武器架偏武器；棺椁偏封存布料、祭器与徽记。稀有例外必须有可读的来源线索。
2. **一次出发内，搜索点和掉落固定。**关闭重开、重连或反复触发敌人招式都不重掷。离开后重新出发再生成新的区域变化。
3. **危险先有可观察的迹象。**活蜂巢有蜂鸣，苏醒石棺有裂纹与动静，狼巢有足迹；玩家选择是否冒险。普通箱子不无提示地变成强制战斗。
4. **重复怪保留规则。**同一蓝史莱姆在神殿与湿地拥有一致招式与掉落；区域差别主要来自敌人组合、搜索对象与环境叙事。
5. **治疗、召唤、奖励有上限。**敌人的自愈不产生额外可搜凝胶，召唤物不无限生成奖励；常规回复依赖有限实体消耗。
6. **每区有自己的主要收获。**古道偏入门物资，神殿偏祭器与贵重品，废塔偏法具与辅助，营地偏物理装备，湿地偏药物与种植资源。
7. **强敌有多种应对方式。**冰能减攻、火能压制部分修复，但不用元素配装也有清晰的攻击与格挡通路。

## 14. 首批内容建议

世界观先覆盖五区；若之后制作首批可玩样例，可抽取能验证主循环的一组：林间古道与苔封神殿、弓手与剑盾哥布林、三色史莱姆、森林狼、穴蝠、裹尸守卫和根棺祭司。红史莱姆落在神殿仍有火晶发热的祭火石龛，蓝史莱姆在蓄水池，绿色在林地。各区先展示 4～6 类搜索对象，其余作为后续填充；这只是体验建议，不是本轮确认的开发排期。

首批优先体验四件事：看见敌人就能猜到其战术；看见搜索对象就能猜到物资倾向；拿到实体后能理解关联牌；带着值钱东西时会认真考虑撤离。废塔、营地与湿地再沿同一套关联补齐，而不是另做互不相通的三套内容。
